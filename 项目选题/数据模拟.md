# 模拟数据的生成：

## 1.虚拟水表设备：

### 支持功能：

* 根据**一天不同时段**，动态调整**流量**和**水温**。

* 根据不同的季节，动态调整**水温**。

* 根据水流量，动态计算**水压**。

* 支持异常事件的模拟，现已支持：**爆管**，**漏水**。

水表数据的数据结构如下：

```json
{
 "device": 1, 
 "deviceId": "11001009", 
 "flow": 0.132, 
 "pressure": 0.45, 
 "waterTem": 17.626, 
 "timeStamp": "2026-01-07T01:07:05.51545731", 
 "totalUsage": 1.056
 "isOpen": "normal", 
 "status": "normal", 
}
```

## 2.虚拟水质传感器：

### 支持功能：

* 根据季节，动态调整**Ph**值和**浊度**。
* 根据季节和浊度，动态调整**含氯量**。

```json
{
 "device":2,
 "deviceId":"20100001",
 "timeStamp":"2026-01-07T17:10:57.0633665",
 "ph":6.867,
 "turbidity":0.717,
 "chlorine":0.485,
 "status":"normal"
}
```
