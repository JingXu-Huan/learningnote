# 关于数据库备份的命令🫡(仅展示逻辑备份)

这下不担心数据丢啦~😍🎉

## 🎉备份操作

### ✅ 1. 单库备份

```bash
mysqldump -u root -p 数据库名 > backup.sql
```

执行后输入密码，就会生成一个 `backup.sql` 文件，里面包含了建表语句和插入语句。

### ✅ 2. 多库或全库备份

```bash
mysqldump -u root -p --databases db1 db2 > multi_backup.sql

mysqldump -u root -p --all-databases > all_backup.sql
```

备份所有数据库。

### ✅ 3. 部分表备份

```bash
mysqldump -u root -p 数据库名 表1 表2 > tables_backup.sql
```

### ✅ 4. 带条件备份（只导出部分数据）

```bash
mysqldump -u root -p 数据库名 表名 --where="id < 1000" > part_data.sql
```

### ✅ 5. 压缩备份

```bash
mysqldump -u root -p 数据库名 | gzip > backup.sql.gz
```

## 😊恢复操作

逻辑备份恢复最简单：

```bash
mysql -u root -p 数据库名 < backup.sql
```

如果是压缩的：

```bash
gunzip < backup.sql.gz | mysql -u root -p 数据库名
```
