# 分页查询

## 原始方式

* ```mysql
  -- 起始索引 = (页码-1) * 每页展示的记录数
  select e.* , d.name from emp e left join dept d on e.dept_id = d.id limit 0,5;
  ```

## Page Helper

**注意 使用Page Helper时,你的SQL语句不能加分号**

*  Page Helper 是第三方提供的在Mybatis框架中用来实现分页的插件,用来简化分页操作,提高开发效率。

  ![image-20250720172348557](C:\Users\24053\AppData\Roaming\Typora\typora-user-images\image-20250720172348557.png)

* 使用方法：

  1. 引入**Page Helper** 的依赖：

     ```xml
     <dependency>
     	<groupId>com.github.pagehelper</groupId>
     	<artifactId>pagehelper-spring-boot-starter</artifactId>
     	<version>1.4.7</version>
     </dependency>
     ```
  
  2. 定义**mapper**接口的查询方法。
  
  3. 在**Service**方法中实现分页查询。

<img src="C:\Users\24053\AppData\Roaming\Typora\typora-user-images\image-20250720174905690.png" alt="image-20250720174905690" style="zoom:25%;" />

* Page Helper 原理：

  拦截SQL语句。count(0) 等同于 聚合函数 count(*)

  加上 limit；

```mysql
==>  Preparing: SELECT count(0) FROM emp e LEFT JOIN dept d ON e.dept_id = d.id
==> Parameters: 
<==    Columns: count(0)
<==        Row: 30
<==      Total: 1
==>  Preparing: select e.* , d.name as deptName from emp e left join dept d on e.dept_id = d.id order by e.update_time desc LIMIT ?, ?
```

## 注意

* ***PageHelper仅能对紧跟其后的第一个查询操作进行分页处理。***
