# 其它注解

* 日期格式化 `@DateTimeFormat`

  ```java
  @DateTimeFormat(pattern = "yyyy-MM-dd")
  //使用此注解来格式化得到的日期格式
  //注意：用于接收请求参数（@RequestParam / @ModelAttribute）的日期格式化
  ```

* JSON日期格式化 `@JsonFormat`

  ```java
  @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
  //使用此注解来格式化响应给前端的JSON日期格式
  //注意：@DateTimeFormat 用于接收，@JsonFormat 用于响应
  ```

* 跨域注解 `@CrossOrigin`

  ```java
  @CrossOrigin(origins = "*")
  //允许所有来源的跨域请求（开发环境使用）
  //生产环境应指定具体域名
  ```

* 忽略响应字段 `@JsonIgnore`

  ```java
  @JsonIgnore
  private String password;
  //序列化JSON时忽略此字段
  ```

* 自定义别名 `@JsonProperty`

  ```java
  @JsonProperty("user_name")
  private String userName;
  //JSON序列化时使用指定的字段名
  ```
