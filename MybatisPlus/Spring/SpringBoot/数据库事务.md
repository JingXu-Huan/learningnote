# 框架中如何处理事务——控制事务传播行为

## 😘注解 `@Transactional` 

*  作用:将当前方法交给spring进行事务管理,方法执行前,开启事务;成功执行完毕,提交事务;出现异常,回滚事务。

*  位置:业务(service)层的方法上、类上、接口上。

  ```java
  @Transactional
      @Override
      public void save(Emp emp) {
          emp.setCreateTime(LocalDateTime.now());
          emp.setUpdateTime(LocalDateTime.now());
          empMapper.insert(emp);
          List<EmpExpr> exprList = emp.getExprList();
          if (!CollectionUtils.isEmpty(exprList)) {
              exprList.forEach(empExpr -> {
                  empExpr.setEmpId(emp.getId());
              });
              empExprMapper.insertBatch(exprList);
          }
      }
  //加在方法上
  ```
  **注意 默认的`@Transactional` 仅仅在 运行时异常`RuntimeException`才会回滚。**
  
  如果想用在所有异常发生时，就回滚事务，我们需要：
  
  ```java
  @Transactional(rollbackFor = {Exception.class})
  ```
  
  也可指定某些异常回滚。

## 两种常见参数：

*  ✅ `REQUIRED` vs `REQUIRES_NEW` 总结

|     属性名     |                             简述                             |                           使用场景                           |
| :------------: | :----------------------------------------------------------: | :----------------------------------------------------------: |
|   `REQUIRED`   |                 如果有事务就加入，没有就新建                 |              ✅ **默认值**，适用于大多数业务逻辑              |
| `REQUIRES_NEW` | **总是开启新事务**，挂起当前事务 原事务的回滚与否不影响当前事务 | ✅ 适用于希望两个事务**互不影响**的情况，例如： 记录日志、补偿机制、发送通知等 |



------

### 🎯使用场景建议：

- **REQUIRED（默认）**
  - 同一个事务中操作多张表、多个步骤，一起提交或一起回滚。
  - 更适用于整体成功才算成功的业务流程。
  
- **REQUIRES_NEW**
  - 子操作不应影响主操作的回滚行为，必须**强制执行**。
  
  - 典型场景：
    - 主业务失败，但日志仍要保存。
    
    - 主业务失败，但发送短信/邮件不能漏。
    
    - 做事务补偿或记录异常行为。
    
    ------

*在 Spring 中，**挂起（Suspend）**指的是：*

> ***当前线程中已存在的事务被“暂时中止”，以便开启一个新的事务，等新的事务执行完后再“恢复”原来的事务。***

### 总结

| 传播行为      | 事务存在时行为           | 事务不存在时行为 |
| ------------- | ------------------------ | ---------------- |
| REQUIRED      | 加入当前事务             | 新建事务         |
| REQUIRES_NEW  | 挂起当前事务，新建事务   | 新建事务         |
| SUPPORTS      | 加入当前事务             | 以非事务方式执行 |
| NOT_SUPPORTED | 挂起当前事务，非事务执行 | 非事务执行       |
| MANDATORY     | 加入当前事务             | 抛异常           |
| NEVER         | 抛异常                   | 非事务执行       |
| NESTED        | 开启嵌套事务（保存点）   | 新建事务         |
