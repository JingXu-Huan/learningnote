# 阻塞队列使用示例

```java
RReliableQueue<MyObject> rq = redisson.getReliableQueue("myqueue");

MyObject data = new MyObject();

Message<MyObject> msg = rq.add(QueueAddArgs.messages(MessageArgs.payload(data)
                                                       .deliveryLimit(10)
                                                       .timeToLive(Duration.ofDays(24))
                                                       .header("key1", new MyDataValue())
                                                       .header("key2", new MyDataValue())
                                                       .delay(Duration.ofSeconds(45))
                                                       .priority(3)
                                                       .deduplicationById("myid", Duration.ofHours(23))));

String id = msg.getId();
MyObject payload = msg.getPayload();
Map<String, MyDataValue> headers = msg.getHeaders();

// adding messages in a batch
List<Message<MyObject>> msgs =  rq.addMany(QueueAddArgs.messages(MessageArgs.payload(data1), 
                                                                 MessageArgs.payload(data2), 
                                                                 MessageArgs.payload(data3)));
```

### 1️⃣ `MessageArgs.payload(data)` 必须参数

- 指定消息的主体内容（payload），也就是你要放入队列的数据对象 `data`。

  **以下均为可选参数：**

------

### 2️⃣ `.deliveryLimit(10)`

- 消息最大 **重试次数**。
- 如果消息处理失败，最多会尝试 **10 次**，超出次数后会被丢弃或放入死信队列（如果有配置）。

------

### 3️⃣ `.timeToLive(Duration.ofDays(24))`

- 消息在队列中的 **生存时间 TTL**。
- 这里设置 **24 天**，过期后消息会自动删除，不再可消费。

------

### 4️⃣ `.header("key1", new MyDataValue())` / `.header("key2", new MyDataValue())`

- 给消息加 **自定义头信息**（headers），相当于消息的元数据，方便消费端处理或分类。

------

### 5️⃣ `.delay(Duration.ofSeconds(45))`

- **延迟投递**，消息在队列中等待 **45 秒**后才可被消费。

------

### 6️⃣ `.priority(3)`

- 消息优先级。
- 数值越大优先级越高（一般），消费时高优先级消息会先处理。
- 此参数的范围是[0,9]

------

### 7️⃣ `.deduplicationById("myid", Duration.ofHours(23))`

- 消息 **去重**。
- 如果 23 小时内队列中已有 ID 为 `"myid"` 的消息，新的消息会被丢弃。
- 防止重复发送相同消息。

------

### 8️⃣ `rq.add(QueueAddArgs.messages(...))`

- 把 **单条消息**加入队列，返回 `Message<MyObject>`，可以获取消息 ID、payload 和 headers。

------

### 9️⃣ `rq.addMany(QueueAddArgs.messages(...))`

- **批量添加消息**，一次性加入多条消息，参数是 `MessageArgs.payload(...)` 的数组或列表。
- 支持批量操作，比逐条 `add` 更高效。
