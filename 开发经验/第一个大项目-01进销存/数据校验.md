# `Spring`常用的数据校验注解 

🤩再也不用担心前端传的数据有问题了🤩

------

### 🌱 字符串相关

😊作用在`DTO`的字段上

| 注解                | 作用                                                      | 示例                                                         |
| ------------------- | --------------------------------------------------------- | ------------------------------------------------------------ |
| `@NotBlank`         | **字符串不能为空且去除空格后长度>0**（只适用于 `String`） | `@NotBlank(message = "用户名不能为空")`                      |
| `@NotEmpty`         | **集合、字符串、数组都不能为 null 且长度 > 0**            | `@NotEmpty(message = "列表不能为空")`                        |
| `@NotNull`          | 仅检查 **不为 null**，不关心长度                          | `@NotNull(message = "性别不能为空")`                         |
| `@Size(min=, max=)` | 限制**字符串**、**集合**、**数组**的长度范围              | `@Size(min = 6, max = 16, message = "密码长度应为6~16位")`   |
| `@Pattern(regexp=)` | 校验**正则表达式**                                        | `@Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式错误")` |

------

### 🔢 数值类型

| 注解                           | 作用                     | 示例                                                         |
| ------------------------------ | ------------------------ | ------------------------------------------------------------ |
| `@Min(value)`                  | 数值不能小于某值         | `@Min(value = 1, message = "年龄必须大于0")`                 |
| `@Max(value)`                  | 数值不能大于某值         | `@Max(value = 120, message = "年龄不能超过120")`             |
| `@Positive`                    | 必须为正数（>0）         | `@Positive(message = "数量必须为正")`                        |
| `@PositiveOrZero`              | 必须≥0                   | `@PositiveOrZero`                                            |
| `@Negative`                    | 必须为负数（<0）         | `@Negative`                                                  |
| `@NegativeOrZero`              | 必须≤0                   | `@NegativeOrZero`                                            |
| `@Digits(integer=, fraction=)` | 限制整数位和小数位的长度 | `@Digits(integer = 5, fraction = 2, message = "价格格式错误")` |

------

### 📅 日期时间

| 注解               | 作用             | 示例                                      |
| ------------------ | ---------------- | ----------------------------------------- |
| `@Past`            | 日期必须是过去的 | `@Past(message = "生日必须是过去的时间")` |
| `@PastOrPresent`   | 过去或现在       | `@PastOrPresent`                          |
| `@Future`          | 日期必须是未来的 | `@Future(message = "预约时间必须是未来")` |
| `@FutureOrPresent` | 未来或现在       | `@FutureOrPresent`                        |

------

### 📦 集合与对象

| 注解                           | 作用                         | 示例                                   |
| ------------------------------ | ---------------------------- | -------------------------------------- |
| `@Valid`                       | 级联校验（用于校验嵌套对象） | 在 `List<UserDTO>` 或另一个 DTO 上使用 |
| `@AssertTrue` / `@AssertFalse` | 字段值必须为 true / false    | 常用于逻辑条件校验                     |

------

### ✨ 进阶扩展（Hibernate Validator 提供）

Hibernate Validator 是 Spring Boot 默认使用的实现，它还扩展了一些实用注解：

| 注解                | 作用                             | 示例                                 |
| ------------------- | -------------------------------- | ------------------------------------ |
| `@Email`            | 校验邮箱格式                     | `@Email(message = "邮箱格式不正确")` |
| `@Length(min, max)` | 字符串长度限制（类似 @Size）     | `@Length(min = 3, max = 20)`         |
| `@Range(min, max)`  | 数值范围限制（适用于 int、long） | `@Range(min = 1, max = 100)`         |
| `@URL`              | 校验 URL 格式                    | `@URL(message = "URL格式错误")`      |
| `@CreditCardNumber` | 校验信用卡号格式                 | `@CreditCardNumber`                  |

### 🎯 启用验证

在 Controller 层中配合使用：

```java
@PostMapping("/add")
public ResponseEntity<?> add(@Valid @RequestBody SampleAddDTO dto) {
    // 如果校验失败，Spring 会自动抛出 MethodArgumentNotValidException 
    // 这里我们可以自定义一个全局异常处理器
    // 参加本目录的 全局异常处理器.md 文档
    return ResponseEntity.ok("success");
}
```

或者在类上加 `@Validated`：

```java
@RestController
@Validated
public class SampleController { ... }
```
### 🎉👌 需要导入的依赖

```xml
 <!-- 实体校验 -->
<dependency>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```
