## 😎关于`ArrayList`

* 注意 `new` 出的 `arrayList` 的默认容量并不是10，`arrayList` 初始化的容量是0；

* 只有我们调用`add`方法时，才会创建一个长度为`10`的数组`elementDate`；

* 每次`add`时 ，指针`size`++;

* 当`size`大于数组长度时，触发扩容操作 `grow()`；

* 扩容后的新数组长度是原数组的1.5倍，这样做是为了性能和内存的平衡；

* 注意 `arrayList`不是线程安全的；

* `arrayList`的插入删除的性能很差，最坏的情况下，时间复杂度是`O(n)`;

* 因此，在使用`arrayList`时，要避免经常在数组的中间位置插入删除元素。

* 如需经常做此操作，建议使用`LinkedList`。

* 详细的扩容操作：

  ```java
  扩容逻辑在 grow(int minCapacity) 方法里：
  先算新容量 = 旧容量 + 旧容量 >> 1（即 1.5 倍）。
  如果新容量依旧小于你需要的最小容量 minCapacity，就会直接把新容量提升到 minCapacity。
  如果超过了 MAX_ARRAY_SIZE（Integer.MAX_VALUE - 8），就会调用 hugeCapacity 兜底。
  ```
  
* 有哪些接口可以使用`ArrayList`?

  ```java
  List<E>
  //最主要的接口，定义了有序集合（顺序存储、允许重复）的操作，比如：
  add(E e);
  remove(Object o);
  get(int index);
  set(int index, E element);
  size();
  ```
