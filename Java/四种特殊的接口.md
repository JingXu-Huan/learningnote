### 1. **`Supplier<T> —— 供给型接口`**

- 含义：不需要输入，直接给你一个结果。
- 方法：`T get()`
- 理解：就像一个工厂或者“零食机”，你摇一摇，它就吐出来东西。

例子：

```java
Supplier<String> supplier = () -> "景旭";
System.out.println(supplier.get()); // 输出：景旭
```

这里它就是“景旭制造机”。

------

### 2. **`Consumer<T> —— 消费型接口`**

- 含义：需要一个输入，用它做点事，但**没有返回值**。
- 方法：`void accept(T t)`
- 理解：就像垃圾桶，往里面扔点东西，它会消化掉，但不会还你。

例子：

```java
Consumer<String> consumer = s -> System.out.println("名字是：" + s);
consumer.accept("景桓"); // 输出：名字是：景桓
```

这里它“消费”了一个字符串，然后打印出来。

------

### 3. **`Function<T,R>` —— 函数型接口**

- 含义：输入一个参数 T，返回一个结果 R。
- 方法：`R apply(T t)`
- 理解：就是一个函数映射关系：`T -> R`。像数学里的 f(x) = y。

例子：

```java
Function<String, Integer> function = s -> s.length();
System.out.println(function.apply("小旭")); // 输出：2
```

这里输入字符串 `"小旭"`，输出它的长度 `2`。

------

### 4. **`Predicate<T>` —— 断言型接口**

- 含义：输入一个参数 T，返回一个布尔值（true/false）。
- 方法：`boolean test(T t)`
- 理解：就是个“测试器”，判断某个条件是否成立。

例子：

```java
Predicate<Integer> predicate = age -> age > 18;
System.out.println(predicate.test(20)); // 输出：true
```

这里就是检查一个年龄是否大于 18。

------

### 小总结

- **`Supplier`**：我来供给 → **没有输入，有输出**。
- **`Consumer`**：我来消费 → **有输入，没有输出**。
- **`Function`**：我来转换 → **有输入，有输出**。
- **`Predicate`**：我来判断 → **有输入，输出布尔值**。

这四个接口基本覆盖了日常编程里 **生产、消费、转换、判断** 四种常见场景，配合 `stream()` 能写出非常简洁的代码。
