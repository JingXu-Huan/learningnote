2. 用过IoC和AOP吗，分别是什么

   ```
   ioc是一种设计思想,即控制反转，将创建对象的控制权从开发者手中转移到spring application context中，实现代码的解耦。
   aop是一种面向切面的思想，通过前置通知，环绕通知，后置通知，可以对需要做一样操作的方法统一进行修改，而不用每个方法都做更改
   ```

3. 为什么使用Autowired注解就可以注入/装配，如果类名相同怎么注入(?)

   ```
   如果类名相同，spring容器回去查看是否标注了其它注解，例如@qualify来精确指定某个bean @Primaryzhi'ding，如果没有，那么就看变量名称，如果还是匹配不到那个bean，spring默认情况就会报错(NosuchbeanException)
   ```

4. 怎么看sql是否走了索引

   ```
   通过对执行的sql语句前面加上explain关键字，查看执行计划，看返回的结果，里面有一个字段会表明走了哪些索引。
   ```

7. 线上某个接口调用耗时过长，如何排查

   ```
   1.排查请求是否正确得到了这个接口 如果压根没到这个接口，那么就检查发送那个请求的路径，参数等
   2.重试几次，看是偶发还是一直出现
   3.如果是偶发，排查是不是网络带宽的问题
   3.如果是一直出现，可以排查是不是有慢sql，代码的问题 对应去做索引优化，代码重构等等
   ```
