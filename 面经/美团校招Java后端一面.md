1.rocketMQ在项目起到的作用

```
rocketmq属于消息队列的一种，常用于以下情况：
当主线程的任务已经完成可以返回时，可能还需要调用其他服务，但这些对于主线程来说并不是必须的，此时将消息发送到消息队列中，把同步调用转化成异步调用，提高了主线程的响应速度，用户体验更好，降低了代码的耦合。
```

```
项目中采用了分布式日志的方案，将这些消息发送到mq的同时，也会通过ELK再存一份，如果rocketmq消息丢失，可以查询索引库。
```

6.讲讲aop?你是怎么用的?

```
aop是面向切面的一种编程思想，通过aop可以将一系列重复的方法，配置到这样的一个切面类中，然后通过切入点表达式或者自定义注解，标记要操作的类。这些包括前置通知，环绕通知，后置通知等。切面类能够减少代码量，更加易读，可维护。
```
