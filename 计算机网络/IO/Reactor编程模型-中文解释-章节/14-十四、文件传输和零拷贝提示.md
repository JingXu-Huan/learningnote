# 十四、文件传输和零拷贝提示

PDF 还提到了 `FileChannel`、内存映射文件和 direct buffer。

文件传输时，数据路径可能是：

```text
磁盘 -> 用户态 Buffer -> Socket -> 网络
```

这条路径可能产生多次复制。`FileChannel.transferTo()`、`transferFrom()` 和内存映射文件有机会减少用户态复制，某些操作系统还可以使用内核级的零拷贝机制。

但“零拷贝”不是绝对不会发生任何复制，而是减少特定路径中的数据复制。它是否有收益，取决于：

- 文件大小；
- 连接持续时间；
- 操作系统和文件系统；
- 网络设备；
- 是否需要修改数据；
- 创建和维护直接内存的成本。
