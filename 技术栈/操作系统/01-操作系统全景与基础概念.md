# 01 操作系统全景与基础概念

[返回教程目录](操作系统教程.md) · [下一章：进程与线程](02-进程线程与通信.md)

## 本章目标

理解操作系统的职责，区分并发与并行、用户态与内核态、系统调用与普通函数调用、中断与异常。

## 1. 操作系统到底做什么

假设浏览器正在播放视频，IDE 正在编译，聊天软件正在收消息。它们都要使用 CPU、内存、磁盘和网卡。操作系统需要决定谁先运行、怎样分配内存、如何访问设备，以及怎样防止一个程序破坏另一个程序。

因此，操作系统可以从三个角度理解：

| 角度 | 核心作用 | 例子 |
| --- | --- | --- |
| 资源管理者 | 分配并回收资源 | 调度 CPU、分配内存、管理磁盘空间 |
| 抽象提供者 | 把复杂硬件包装成稳定接口 | 用文件读写接口访问存储设备 |
| 保护与协调者 | 隔离程序，提供受控协作方式 | 权限检查、进程隔离、进程间通信 |

内核是操作系统的核心部分。桌面、命令解释器等属于更上层的软件；操作系统并不等于图形界面。

## 2. 常见特征与运行方式

### 并发与并行

**并发**：多个任务在一段时间内交替推进。单核 CPU 可以快速切换任务，实现并发。

**并行**：多个任务在同一时刻执行。多个 CPU 核可以分别执行不同任务，实现并行。

举例：一个人轮流炒菜和煮汤，是并发；两个人各做一道菜，是并行。注意“看起来同时进行”不足以证明 CPU 上真正并行。

### 共享、虚拟和异步

- **共享**：多个任务使用系统资源。有的资源可同时使用，有的必须互斥访问。
- **虚拟**：用管理机制让程序获得便于使用的资源视图，例如每个进程看到自己的虚拟地址空间。
- **异步**：在经典教材中，指并发任务走走停停、推进速度不可预知；这与后面讨论的“异步 I/O”不是同一个层面的术语。

### 批处理、分时与实时

| 类型 | 主要目标 | 典型理解 |
| --- | --- | --- |
| 批处理系统 | 提高资源利用率和吞吐量 | 一批作业自动执行，减少人工干预 |
| 分时系统 | 让多个用户及时得到响应 | 把 CPU 时间分给不同任务 |
| 实时系统 | 在规定时间约束内完成任务 | 控制系统需要按时响应 |

实时不只是“速度快”：硬实时任务错过截止时间可能造成不可接受的结果；软实时允许一定程度的超时，但会降低服务质量。

## 3. 用户态与内核态

CPU 提供不同权限级别。普通应用通常在**用户态**运行，访问受限；操作系统内核在**内核态**运行，可以执行特权操作并管理硬件。

两者的目的在于保护：应用不能随意改页表、控制设备或访问其他进程的受保护内存。

应用需要内核服务时，可以发起**系统调用**。例如申请打开文件、读取数据、创建进程。系统会检查参数和权限，然后执行相应服务。

一次典型文件读取，可以概括为：

1. 应用提出读取请求。
2. 通过系统调用进入内核服务。
3. 内核检查权限，并从缓存或设备取得数据。
4. 结果返回应用，应用继续执行。

**普通函数调用不一定是系统调用。** 字符串长度计算可以完全在用户态完成；库函数也可能先使用缓冲区，只有必要时才向内核提出请求。

## 4. 中断、异常与系统调用

| 概念 | 典型来源 | 例子 |
| --- | --- | --- |
| 外部中断 | CPU 外部设备或定时器 | 网卡收包、I/O 完成、时钟中断 |
| 异常 | 当前指令执行引发的事件 | 缺页、除零、非法访问 |
| 系统调用 | 应用主动请求内核服务 | 文件读写、进程管理 |

不同教材对“广义中断”“陷入”的分类可能不同。答题时先采用课程定义，再说明事件来源。

**进入内核不意味着一定切换进程。** 当前线程可以执行完系统调用后继续运行；只有发生调度，才会把执行权交给其他任务。

## 5. 拓展：机制与策略

机制解决“能怎样做”，策略解决“选择怎样做”。

例如保存和恢复任务上下文是机制；决定下一次运行哪个任务是调度策略。理解这一区分，有助于解释为什么多个调度算法可以共用同一套运行基础。

## 期末答题模板

“操作系统是管理计算机软硬件资源、组织程序执行并为用户和应用提供服务的系统软件。它通过进程调度、内存管理、文件系统和设备管理等机制，提高资源利用率，并实现保护和协作。”

不要只写“操作系统管理电脑”，要点出资源、执行和接口。

## 自测与答案

1. 单核 CPU 能否并发？能否让两个普通任务同一时刻都在该核上执行？
2. 应用调用一个计算字符串长度的函数，是否一定进入内核？
3. 一次缺页属于外部设备中断吗？
4. 一次系统调用是否必然导致另一个进程运行？

**答案**：①能并发，但不能在同一核同一时刻执行两个普通任务；②不一定；③通常属于当前访存引发的异常；④不必然，内核服务结束后可继续运行原线程。
