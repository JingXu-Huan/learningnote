# 12 面试问答与追问

[返回教程目录](操作系统教程.md) · [下一章：复习计划](13-复习计划与考前速查.md)

## 使用方法

每次选 5 个问题，先口述 30～60 秒，再看答案。回答按“定义 → 机制 → 场景 → 条件与代价”组织，不要一开口就堆名词。

下面的回答是表达参考，应结合自己实际理解和做过的项目。没有遇到过某个故障，可以说明排查思路，不要把练习案例说成真实经历。

## 1. 进程与线程有什么区别

**参考回答**：进程提供运行所需的资源环境，通常有独立地址空间；线程是其中的一条执行流。同一进程的线程共享地址空间和很多资源，但各自有栈和执行上下文。线程之间共享数据方便，却需要同步；进程之间通常隔离更强，可通过 IPC 协作。

**追问：为什么线程切换通常更轻？** 同进程线程切换通常不需切换到另一进程的地址空间，但仍有调度、状态保存和缓存局部性成本。

## 2. 并发与并行有什么区别

**参考回答**：并发描述多个任务在一段时间内交替推进；并行描述同一时刻执行多个任务。单核可实现并发，多核可以让任务并行。并发程序需要正确处理交错，即使部署到单核也可能出现竞态。

**追问：开 100 个线程能得到 100 倍性能吗？** 不能，受可用核心、任务等待、共享锁和其他资源限制。

## 3. 什么是上下文切换

**参考回答**：系统把执行权交给另一个任务前，要保存当前执行状态并恢复目标任务状态。成本包括调度与保存恢复，也可能包含缓存和地址转换局部性变化。任务数多且频繁切换，可能使有效工作比例下降。

**追问：系统调用就是上下文切换吗？** 系统调用进入内核服务，不一定调度另一个任务；两者应分别讨论。

## 4. 为什么需要用户态与内核态

**参考回答**：通过权限区分保护系统资源。普通应用在受限权限下运行，需要管理文件、内存或设备时，通过受控接口请求内核服务。内核检查参数与权限，防止应用随意破坏其他任务或系统状态。

**追问：库函数一定进入内核吗？** 不一定，计算或缓冲处理可以在用户态完成。

## 5. 进程有哪些通信方式

**参考回答**：常见有管道、消息队列、共享内存、信号和 Socket。选择取决于数据量、消息边界、本机还是跨机器，以及同步需求。共享内存可减少某些数据复制，但仍需协调访问；Socket 可以用于本机或跨机器通信。

**追问：共享内存为什么还要加锁？** 共享只保证访问同一片区域，不保证复杂更新的原子性或协作顺序。

## 6. 协程为什么适合大量 I/O 任务

**参考回答**：协程可以把等待组织成可挂起的任务，在合适的运行时下减少为每个等待任务配备独立平台线程的成本。但它依赖调度和接口支持；CPU 计算仍受核心限制，某些阻塞调用仍可能阻塞底层执行线程。

**追问：协程一定比线程快吗？** 要看任务、运行时、调度成本及实际瓶颈，不能仅凭抽象类型判断。

## 7. 锁解决什么问题

**参考回答**：锁用于保护共享资源访问，使相关操作按所需规则执行。例如库存检查与扣减需要作为完整业务过程协调。锁的范围应覆盖要维护的不变量，但不宜包含无关或长时间等待的工作。

**追问：线程安全容器能保证复合业务安全吗？** 不能自动保证，多步“先检查再修改”仍可能交错。

## 8. 互斥锁、信号量、条件变量有什么区别

**参考回答**：互斥锁通常用于一个持有者独占临界区；计数信号量管理一定数量的许可，也可用于事件同步；条件变量让线程等待共享状态满足条件，并配合锁检查与改变状态。

**追问：条件变量为什么要反复检查条件？** 可能伪唤醒，也可能别的任务先消耗了资源，唤醒不是对条件持续成立的保证。

## 9. 自旋锁与阻塞式锁怎样取舍

**参考回答**：自旋等待会消耗 CPU，可避免某些睡眠唤醒成本，适合非常短的临界区和合适的并行环境；阻塞等待让出执行机会，更适合较长等待。持锁者不能及时运行时，自旋会浪费资源。

**追问：业务代码应该自己写自旋吗？** 通常使用成熟同步库，由测量和具体语义决定方案。

## 10. 死锁如何产生、如何避免

**参考回答**：在经典模型中，互斥、占有且等待、不可剥夺和循环等待共同构成死锁发生的必要条件。工程上常用统一锁顺序、减少嵌套与持锁时间、谨慎使用超时和恢复机制降低风险。

**追问：超时就算解决了吗？** 还要释放已有资源，处理部分完成的状态，并设计可安全重试或回滚的路径。

## 11. 死锁、活锁和饥饿有什么区别

**参考回答**：死锁是任务相互等待而无法推进；活锁是不断尝试或让步，却没有实际进展；饥饿是某个任务长期得不到资源，但其他任务仍在推进。三者需要不同治理方式，例如锁顺序、公平性或重试退避。

**追问：没死锁就一定公平吗？** 不一定，一个低优先级任务仍可能一直得不到服务。

## 12. 虚拟内存有什么作用

**参考回答**：虚拟内存提供统一的地址视图，实现映射、隔离、保护和共享，并允许按需准备页面。每个进程使用自己的地址空间，硬件与操作系统把地址转换到物理内存。它也可支持页面回收和后备存储使用。

**追问：虚拟内存就是交换空间吗？** 不是，交换是相关机制之一，地址映射与保护同样重要。

## 13. 分页、分段与 TLB 分别是什么

**参考回答**：分页按固定大小管理地址空间与物理页框；分段按逻辑单位划分，段长度可不同。TLB 缓存地址转换信息，减少反复查询页表的开销；它不是存储数据内容的普通数据缓存。

**追问：TLB 未命中一定缺页吗？** 不一定，可能只是映射不在 TLB 中，而页面和页表都已驻留。

## 14. 缺页是不是程序出错

**参考回答**：不一定。按需加载时，合法页面暂未建立可用映射，可以通过缺页处理准备页面后继续运行；写时复制也可能触发相关处理。是否需要磁盘取决于具体原因。非法地址或权限违规则不能按正常装入处理。

**追问：为什么缺页会显著增加延迟？** 某些缺页涉及存储访问，耗时远大于普通内存访问，即使发生概率低也会影响平均值和尾延迟。

## 15. FIFO、LRU 与 OPT 怎么比较

**参考回答**：FIFO 淘汰最早进入的页，LRU 淘汰最久未访问的页，OPT 依据未来访问淘汰最晚再用的页。OPT 主要作理想基准；LRU 依赖近期规律但有维护成本；FIFO 可能出现增加页框反而增加缺页的 Belady 异常。

**追问：LRU 总比 FIFO 好吗？** 单条引用串不保证；应按具体访问过程比较。

## 16. 什么是写时复制

**参考回答**：先让可共享内容复用同一物理页面，发生写入时再按需要建立独立副本，避免提前复制可能不会修改的内容。Linux fork 使用这一思路，因此创建子进程不意味着立即复制所有父进程页面内容。

**追问：写时复制有没有成本？** 有，映射管理、写入引发的处理和实际复制仍需资源。

## 17. Java 有 GC 为什么还会内存泄漏

**参考回答**：GC 根据可达性等规则回收对象，如果已经不需要的对象仍被缓存、集合、监听器等持有，仍可能无法回收。另外进程还包含本地资源、直接内存等，不能只看 Java 堆。

**追问：内存上涨是不是泄漏？** 不一定，可能是正常缓存或负载增长；需要看对象来源、保留关系与长期趋势。

## 18. 阻塞、非阻塞和异步怎么理解

**参考回答**：阻塞与非阻塞关注暂时不能完成时，调用是等待还是立即返回。异步接口则把操作提交与完成结果交付分开。具体术语要结合 API 定义；有回调不代表一定使用操作系统异步 I/O。

**追问：非阻塞一定高效吗？** 高频率无效轮询仍可能消耗 CPU，通常要结合事件通知或合理调度。

## 19. epoll 为什么适合管理很多连接

**参考回答**：它维护应用注册的兴趣和就绪事件，使事件循环可以处理当前有活动的连接，适合大量连接等待、部分连接活跃的场景。它提供就绪通知，应用通常还需要读写数据，事件处理的成本仍存在。

**追问：能在事件线程中做慢数据库调用吗？** 可能使其他连接等待，应按框架约定把长耗时工作交给合适的执行资源。

## 20. 零拷贝是不是完全不复制

**参考回答**：通常指减少某些软件复制和跨边界的数据搬运，具体省掉哪些步骤取决于机制。设备与内存之间仍要传输数据，也可能存在不可避免的复制。应结合 sendfile 或映射等具体路径说明。

**追问：它为什么可能更快？** 减少 CPU 参与搬运、调用或内存带宽消耗，但收益取决于数据规模和系统路径。

## 21. CPU 不高但服务很慢，怎么排查

**参考回答**：先拆延迟，检查是否在排队、等锁、等连接池或等下游 I/O。结合线程转储、连接池、数据库和网络指标找到主要等待，再做限流、容量调整或瓶颈修复。低 CPU 不能证明不存在资源瓶颈。

**追问：直接加线程会怎样？** 如果瓶颈在数据库或锁，可能增加等待与内存消耗，甚至放大过载。

## 22. 容器与虚拟机有什么区别

**参考回答**：常见 Linux 容器共享宿主环境的内核，通过隔离与资源限制运行应用；虚拟机通常有自己的内核和虚拟硬件环境。容器较轻，但资源限制、内核和安全边界的模型不同。

**追问：宿主还有内存，容器为什么 OOM？** 容器可能触及自己的内存限制；要分开观察进程、容器及宿主指标。

## 三道综合追问

1. “把线程池从 20 扩到 200，吞吐不增但内存涨了。”请同时从 CPU、I/O、锁和线程栈解释。
2. “日志名称已经删除，但磁盘仍满。”请画出目录项、文件对象和打开引用的关系。
3. “磁盘活动很高、接口变慢、CPU 反而下降。”如何区分业务写入压力和内存抖动？

这三题需要跨章节组合。合理回答应提出多个假设、说明证据，再给出与证据对应的措施，而不是立即断定唯一原因。
