## 1. 选择数据结构

先按核心需求选择，不要因为“熟悉列表”就把所有数据都塞进列表。

| 需求 | 首选 | 说明 |
| --- | --- | --- |
| 有顺序、允许重复、需要修改 | `list` | 支持索引、切片、追加与删除 |
| 有顺序、语义固定、不希望修改 | `tuple` | 可用于多返回值、记录、字典键 |
| 按唯一键快速查找 | `dict` | 保存键值映射，保持插入顺序 |
| 去重、成员测试、集合运算 | `set` | 元素唯一，不保证业务顺序 |
| 不可变集合、需要作为键 | `frozenset` | 可哈希的集合版本 |
| Unicode 文本 | `str` | 字符串不可变 |
| 原始字节 | `bytes` | 不可变的二进制序列 |
| 可修改字节缓冲区 | `bytearray` | 可原地修改 |
| 整数等差序列 | `range` | 惰性、占用空间基本固定 |
| 两端频繁进出 | `collections.deque` | 队列和双端队列 |
| 计数 | `collections.Counter` | 元素到出现次数的映射 |

一个订单可自然组合多种结构：

```python
order = {
    "id": 1001,
    "customer": ("Alice", "13800000000"),
    "items": [
        {"sku": "A-01", "quantity": 2},
        {"sku": "B-03", "quantity": 1},
    ],
    "tags": {"paid", "priority"},
}
```

## 2. 序列的共同操作

`str`、`list`、`tuple`、`bytes` 和 `range` 都属于序列，支持一组共同操作。

### 2.1 索引与切片

```python
values = [10, 20, 30, 40, 50]

values[0]      # 10
values[-1]     # 50
values[1:4]    # [20, 30, 40]
values[:3]     # [10, 20, 30]
values[::2]    # [10, 30, 50]
values[::-1]   # [50, 40, 30, 20, 10]
```

切片规则是 `sequence[start:stop:step]`，区间左闭右开。省略边界时会使用合适的起止位置；步长不能为 `0`。

普通索引越界抛出 `IndexError`，切片边界超出范围通常会被安全截断：

```python
values[100:]   # []
```

### 2.2 通用操作

```python
len(values)             # 长度
30 in values            # 成员测试
values + [60, 70]       # 同类序列拼接
[0] * 3                 # [0, 0, 0]
min(values)
max(values)
sum(values)
```

`+`、`*` 通常创建新序列。大型数据处理应避免在循环中反复拼接不可变序列，因为会不断复制已有内容。

### 2.3 解包

```python
point = (10, 20)
x, y = point

head, *body, tail = [1, 2, 3, 4, 5]
```

星号解包的收集结果始终是列表。调用函数或构造新容器时，也可用 `*` 展开可迭代对象、用 `**` 展开映射：

```python
left = [1, 2]
right = [3, 4]
merged = [*left, *right]

base = {"timeout": 3, "retries": 2}
config = {**base, "timeout": 5}
```

## 3. 字符串 `str`

`str` 是不可变的 Unicode 码位序列，适合人类可读文本。网络、文件和数据库中的原始数据通常先以字节存在，再按编码解码为字符串。

### 3.1 创建与转义

```python
single = 'Python'
double = "Python"
multiline = """第一行
第二行"""
quote = "他说：\"你好\""
raw_pattern = r"\d+\.\d+"
```

原始字符串仍有语法边界，例如不能以单个反斜杠结尾。路径处理优先使用 `pathlib.Path`，正则表达式通常使用原始字符串。

### 3.2 查找与判断

```python
text = "  Hello, Python!  "

"Python" in text
text.startswith("  Hello")
text.endswith("!  ")
text.find("Python")       # 找不到返回 -1
text.index("Python")      # 找不到抛出 ValueError
text.count("o")
```

字符类别判断：

```python
"123".isdigit()       # True
"Python".isalpha()    # True
"abc123".isalnum()    # True
"   ".isspace()       # True
"name_1".isidentifier()  # True
```

### 3.3 清理与替换

```python
text.strip()                    # 去除两端空白
text.lstrip()
text.rstrip()
text.replace("Python", "Java")
"unittest.py".removesuffix(".py")
"Bearer token".removeprefix("Bearer ")
```

`strip(chars)` 中的参数是“要去除的字符集合”，不是完整前后缀：

```python
"www.example.com".strip("w.com")  # 结果可能出乎意料
```

需要删除固定前后缀时使用 `removeprefix()` / `removesuffix()`。

### 3.4 拆分与连接

```python
line = "alice,90,backend"
name, score, direction = line.split(",")

words = ["Python", "is", "readable"]
sentence = " ".join(words)
```

连接大量字符串时使用 `separator.join(parts)`，不要在循环里反复执行 `result += part`。

```python
lines = ["first", "second", "third"]
content = "\n".join(lines)
```

`split()` 不传参数时会按任意连续空白拆分，并忽略首尾空白；`split(" ")` 只按单个空格分隔，可能产生空字符串。

### 3.5 大小写与无视大小写比较

```python
name = "Python"
name.lower()
name.upper()
name.title()
name.swapcase()
```

面向 Unicode 的无视大小写比较优先使用 `casefold()`：

```python
left.casefold() == right.casefold()
```

### 3.6 格式化

```python
user = "Alice"
balance = 12345.6
message = f"用户 {user}，余额 {balance:,.2f} 元"
```

对于用户可控的格式模板、日志延迟格式化或国际化场景，应根据框架约定选择方案，不要把不可信字符串直接当作格式模板执行。

### 3.7 Unicode、长度与规范化

`len(text)` 返回 Unicode 码位数量，不保证等于用户看到的“字符数”或终端显示宽度。带组合附加符的文本可能视觉相同、底层表示不同：

```python
import unicodedata

normalized = unicodedata.normalize("NFC", text)
```

账号标识、搜索和跨系统比较是否需要规范化，必须依据业务规则决定；不要对密码原文做擅自变换。

## 4. 列表 `list`

列表是有序、可变、允许重复的对象引用序列。

### 4.1 创建与修改

```python
numbers = [1, 2, 3]
empty = []
from_range = list(range(5))

numbers.append(4)          # 末尾追加一个元素
numbers.extend([5, 6])     # 追加多个元素
numbers.insert(0, 0)       # 指定位置插入
```

注意 `append()` 与 `extend()`：

```python
values = [1, 2]
values.append([3, 4])  # [1, 2, [3, 4]]

values = [1, 2]
values.extend([3, 4])  # [1, 2, 3, 4]
```

### 4.2 删除元素

```python
items = ["a", "b", "c", "b"]

last = items.pop()       # 删除并返回末尾元素
first = items.pop(0)     # 删除并返回索引 0，需移动其余元素
items.remove("b")       # 删除第一个匹配值；找不到抛 ValueError
del items[0:2]           # 按索引或切片删除
items.clear()            # 原地清空
```

栈可直接使用 `append()` / `pop()`；先进先出队列不要用 `pop(0)`，应使用 `collections.deque`。

### 4.3 切片赋值

列表切片可以原地替换，替换长度不必相同：

```python
numbers = [0, 1, 2, 3, 4]
numbers[1:4] = [10, 20]
print(numbers)  # [0, 10, 20, 4]
```

### 4.4 查找与统计

```python
items.index("b")  # 第一次出现的位置；找不到抛 ValueError
items.count("b")
"b" in items
```

列表成员测试要线性扫描。如果只关心大量、频繁的成员判断，通常改用集合。

### 4.5 排序与反转

```python
users = [
    {"name": "Alice", "score": 90},
    {"name": "Bob", "score": 85},
]

users.sort(key=lambda user: user["score"], reverse=True)
users.reverse()
```

- `list.sort()` 原地排序并返回 `None`。
- `sorted(iterable)` 接受任意可迭代对象并返回新列表。
- Python 排序是稳定的：键相等的元素保持原相对顺序。

### 4.6 列表作为栈

```python
stack: list[str] = []
stack.append("task-1")
stack.append("task-2")
current = stack.pop()
```

末尾追加和弹出通常为摊销 `O(1)`。

## 5. 元组 `tuple`

元组是有序、不可变、允许重复的序列，常表达固定结构的记录或不应被替换的一组引用。

### 5.1 创建元组

```python
point = (10, 20)
rgb = 255, 128, 0
empty = ()
single = (42,)  # 单元素元组必须有逗号
```

括号通常用于可读性，真正创建元组的是逗号。

### 5.2 元组解包与多返回值

```python
def min_max(values: list[int]) -> tuple[int, int]:
    return min(values), max(values)


minimum, maximum = min_max([3, 1, 8])
```

函数所谓“返回多个值”，实际是返回一个元组，再由调用方解包。

### 5.3 不可变是浅层的

元组不能重新绑定某个位置，但它引用的可变对象仍可修改：

```python
record = ("Alice", [90, 95])
record[1].append(100)  # 合法
```

包含列表的元组不可哈希，因此不能作为字典键。若需要语义明确、带字段名的不可变记录，可考虑 `typing.NamedTuple`、`collections.namedtuple()` 或冻结的数据类。

## 6. 字典 `dict`

字典保存唯一键到值的映射。Python 3.7+ 语言规范保证字典保持插入顺序，但按键查找仍是它的主要用途。

### 6.1 创建与访问

```python
user = {
    "id": 1001,
    "name": "Alice",
    "active": True,
}

user["name"]             # 键不存在时抛 KeyError
user.get("email")        # 键不存在时返回 None
user.get("email", "-")   # 提供默认值
```

当“键不存在”是程序错误时使用方括号，让错误尽早暴露；缺失是正常情况时使用 `get()` 或显式判断。

### 6.2 新增、更新与删除

```python
user["email"] = "alice@example.com"
user["active"] = False
user.update({"city": "Zhengzhou", "active": True})

email = user.pop("email", None)
last_pair = user.popitem()  # 后进先出
del user["city"]
```

Python 3.9+ 支持字典合并运算符：

```python
defaults = {"timeout": 3, "retries": 2}
custom = {"timeout": 10}

config = defaults | custom  # 右侧同名键覆盖左侧
defaults |= custom          # 原地更新
```

### 6.3 遍历

```python
for key in user:
    print(key)

for key, value in user.items():
    print(key, value)

for value in user.values():
    print(value)
```

`dict.keys()`、`items()`、`values()` 返回动态视图，底层字典变化会反映到视图中。

### 6.4 `setdefault()`

```python
groups: dict[str, list[str]] = {}

for name, department in records:
    groups.setdefault(department, []).append(name)
```

简单场景可用 `setdefault()`；持续分组或计数通常用 `collections.defaultdict` 更清晰。

### 6.5 字典推导式

```python
scores = {"Alice": 90, "Bob": 55, "Carol": 80}
passed = {name: score for name, score in scores.items() if score >= 60}
```

若多个输入项生成相同键，后出现的值覆盖先前值。

### 6.6 反向映射的前提

```python
code_to_name = {1: "Alice", 2: "Bob"}
name_to_code = {name: code for code, name in code_to_name.items()}
```

只有原字典的值可哈希且唯一时，才能无损反转。若值可能重复，应反向映射到列表或集合。

## 7. 集合 `set` 与 `frozenset`

集合保存不重复、可哈希的元素，适合成员测试、去重和数学集合运算。

### 7.1 创建集合

```python
empty_set = set()          # {} 是空字典
tags = {"python", "api", "backend"}
unique_numbers = set([1, 2, 2, 3])
immutable_tags = frozenset({"stable", "public"})
```

不要依赖集合遍历顺序；即使某次运行中看似稳定，也不构成业务保证。

### 7.2 修改与成员测试

```python
tags.add("fastapi")
tags.update(["web", "async"])

tags.remove("web")     # 不存在时抛 KeyError
tags.discard("maybe")  # 不存在也不报错
item = tags.pop()       # 删除并返回任意元素，不是“最后一个”
```

### 7.3 集合运算

```python
backend = {"Python", "Java", "Go"}
data = {"Python", "SQL", "R"}

backend | data   # 并集
backend & data   # 交集
backend - data   # 差集
backend ^ data   # 对称差集

{"Python"} <= backend   # 子集
backend >= {"Java"}     # 超集
backend.isdisjoint({"C"})
```

运算符通常要求两侧都是集合；对应方法可接受任意可迭代对象，例如 `backend.intersection(list_of_names)`。

### 7.4 保序去重

直接 `list(set(items))` 会丢失原顺序。利用字典保持插入顺序：

```python
unique_in_order = list(dict.fromkeys(items))
```

若元素不可哈希，则需要定义唯一键或用循环维护已见键集合。

## 8. 二进制序列 `bytes` 与 `bytearray`

`str` 表示文本，`bytes` 表示原始字节。二者不能在没有明确编码的情况下直接拼接。

### 8.1 编码与解码

```python
text = "你好，Python"
payload = text.encode("utf-8")
restored = payload.decode("utf-8")

assert restored == text
```

- 编码：`str -> bytes`。
- 解码：`bytes -> str`。
- UTF-8 是跨系统文本传输的常见默认选择，但应服从协议或文件的明确约定。

编码不匹配会导致 `UnicodeEncodeError`、`UnicodeDecodeError` 或乱码。不要用忽略错误的方式掩盖数据损坏，除非业务明确允许丢字符。

### 8.2 `bytes` 的元素是整数

```python
data = b"ABC"
data[0]      # 65
data[0:1]    # b'A'
list(data)   # [65, 66, 67]
```

`bytes` 中每个元素范围为 `0~255`。字节字面量中直接写非 ASCII 字符会报语法错误，应先对字符串编码。

### 8.3 可变的 `bytearray`

```python
buffer = bytearray(b"ABC")
buffer[0] = 97
print(buffer)  # bytearray(b'aBC')
```

处理协议帧、二进制缓冲区时，`bytearray` 可减少反复创建对象。只读切片和零复制视图还可了解 `memoryview`。

## 9. `range`

`range` 表示不可变的整数等差序列，只保存起点、终点和步长，空间占用不会随区间长度线性增长。

```python
range(5)          # 0, 1, 2, 3, 4
range(2, 10, 2)   # 2, 4, 6, 8
range(10, 0, -2)  # 10, 8, 6, 4, 2
```

它支持序列操作：

```python
numbers = range(0, 1_000_000, 2)

len(numbers)
100 in numbers
numbers[10]
numbers[5:20:2]  # 仍返回 range
```

需要真正列表时才执行 `list(range(...))`。遍历数据本身时直接遍历数据；只有确实需要整数索引时才用 `range(len(items))`。

## 10. 可变性、哈希与拷贝

### 10.1 可变与不可变

| 类型 | 是否可变 | 通常是否可哈希 |
| --- | --- | --- |
| `int`、`float`、`bool`、`NoneType` | 否 | 是 |
| `str`、`bytes`、`range` | 否 | 是 |
| `tuple` | 否 | 所有元素可哈希时才可哈希 |
| `frozenset` | 否 | 是 |
| `list`、`dict`、`set`、`bytearray` | 是 | 否 |

不可变意味着对象内容不能原地改变，不意味着名称不能重新绑定：

```python
name = "Alice"
name = name.upper()  # 名称改为指向新字符串
```

### 10.2 什么是可哈希

可哈希对象在其生命周期内哈希值保持不变，并可进行相等性比较。字典键和集合元素必须可哈希。

```python
locations = {
    (34.75, 113.62): "Zhengzhou",
}
```

自定义对象若定义相等性和哈希，必须遵守：若 `a == b`，则 `hash(a) == hash(b)`。可变状态通常不适合作为哈希依据。

数字类型之间相等的值会视为同一字典键：

```python
mapping = {1: "integer", True: "boolean"}
print(mapping)  # 只有一个键，因为 1 == True
```

### 10.3 赋值不是复制

```python
original = [1, 2, 3]
alias = original

assert alias is original
alias.append(4)
assert original == [1, 2, 3, 4]
```

### 10.4 浅拷贝

```python
original = [[1, 2], [3, 4]]
shallow = original.copy()

assert shallow is not original
assert shallow[0] is original[0]

shallow[0].append(99)
print(original)  # [[1, 2, 99], [3, 4]]
```

列表切片 `original[:]`、`list(original)` 和 `copy.copy(original)` 也可创建浅拷贝。浅拷贝只复制最外层容器，内部元素仍共享。

### 10.5 深拷贝

```python
from copy import deepcopy

deep = deepcopy(original)
deep[0].append(100)
```

`deepcopy()` 会递归复制，成本更高，也不一定适用于文件句柄、连接、锁等资源对象。很多时候，用不可变数据、明确构造新对象或只复制要修改的分支更安全。

### 10.6 嵌套列表初始化陷阱

```python
# 错误：三行引用同一个内部列表
grid = [[0] * 3] * 3
grid[0][0] = 1

# 正确：每次推导创建独立列表
grid = [[0] * 3 for _ in range(3)]
```

## 11. 推导式与生成器表达式

### 11.1 列表推导式

```python
numbers = range(10)
squares_of_even = [number ** 2 for number in numbers if number % 2 == 0]
```

推荐阅读顺序：先读“对每个 `number`”，再看筛选条件，最后看最前面的输出表达式。

### 11.2 集合与字典推导式

```python
words = ["Python", "python", "FastAPI"]
normalized = {word.casefold() for word in words}

length_by_word = {word: len(word) for word in words}
```

集合推导式会去重；字典推导式的键冲突会后值覆盖前值。

### 11.3 嵌套推导式

```python
matrix = [[1, 2], [3, 4], [5, 6]]
flattened = [value for row in matrix for value in row]
```

它对应的循环顺序是：

```python
flattened = []
for row in matrix:
    for value in row:
        flattened.append(value)
```

超过两层、包含复杂条件或需要异常处理时，应改用普通循环或拆分辅助函数。

### 11.4 生成器表达式

```python
total = sum(number ** 2 for number in range(1_000_000))
```

圆括号形式按需产生元素，不一次性构建完整列表，适合只遍历一次的流水线。它不是元组推导式；Python 没有元组推导式，若要元组需 `tuple(...)`。

### 11.5 推导式中避免副作用

```python
# 不推荐：为了调用 print 而构造一堆 None
[print(item) for item in items]

# 推荐
for item in items:
    print(item)
```

推导式用于构造值，不用于替代所有循环。

## 12. 排序与常用算法

### 12.1 `sorted()` 与键函数

```python
users = [
    {"name": "Bob", "age": 20},
    {"name": "alice", "age": 20},
    {"name": "Carol", "age": 18},
]

by_age_then_name = sorted(
    users,
    key=lambda user: (user["age"], user["name"].casefold()),
)
```

键函数对每个元素计算一次。不要在比较阶段反复执行昂贵操作。

常用键函数工具：

```python
from operator import attrgetter, itemgetter

sorted(rows, key=itemgetter("score"), reverse=True)
sorted(objects, key=attrgetter("created_at"))
```

### 12.2 聚合与判断

```python
sum(numbers)
min(users, key=lambda user: user["score"])
max(users, key=lambda user: user["score"])
any(user["active"] for user in users)
all(user["verified"] for user in users)
```

`any()` 遇到真值就停止，`all()` 遇到假值就停止。注意 `all([])` 为 `True`，`any([])` 为 `False`，这是空集合上的数学约定。

### 12.3 按需求选择算法

| 需求 | 推荐方案 | 原因 |
| --- | --- | --- |
| 偶尔在少量数据中查找 | 直接遍历列表 | 简单，避免额外结构 |
| 对大量数据反复判断存在性 | 预先构造 `set` | 平均 `O(1)` 成员测试 |
| 按唯一标识查对象 | `dict[id] -> object` | 平均 `O(1)` 查找 |
| 保序去重可哈希元素 | `dict.fromkeys(items)` | 保留第一次出现顺序 |
| 获取全部有序结果 | `sorted()` | 清晰且稳定 |
| 获取最小/最大的少量 `k` 个 | `heapq.nsmallest()` / `nlargest()` | 避免对全部数据完整排序 |
| 维护优先级队列 | `heapq` | 堆顶操作 `O(log n)` |
| 在已排序序列中查插入点 | `bisect` | 二分查找 `O(log n)`；列表插入仍为 `O(n)` |
| 先进先出队列 | `collections.deque` | 两端进出 `O(1)` |
| 频率统计 | `collections.Counter` | 语义清晰、接口完整 |

### 12.4 单次遍历替代重复扫描

```python
# 重复扫描
minimum = min(numbers)
maximum = max(numbers)

# 数据量大且来源为一次性迭代器时，可单次处理
iterator = iter(numbers)
first = next(iterator)
minimum = maximum = first

for number in iterator:
    if number < minimum:
        minimum = number
    if number > maximum:
        maximum = number
```

优化前先确认性能瓶颈。对普通列表，两次清晰的 C 层内置遍历有时比一段 Python 层循环更快。

## 13. 时间复杂度速查

下表为 CPython 常见平均情况的数量级，`n` 为容器长度；哈希冲突、对象自定义方法和内存分配都会影响实际表现。

| 操作 | `list` | `dict` | `set` | `deque` |
| --- | --- | --- | --- | --- |
| `len(container)` | `O(1)` | `O(1)` | `O(1)` | `O(1)` |
| 按下标访问 | `O(1)` | 不适用 | 不适用 | 两端 `O(1)`，中间趋近 `O(n)` |
| 成员测试 | `O(n)` | 平均 `O(1)`（键） | 平均 `O(1)` | `O(n)` |
| 末尾追加/弹出 | 摊销 `O(1)` | 不适用 | 不适用 | `O(1)` |
| 开头插入/删除 | `O(n)` | 不适用 | 不适用 | `O(1)` |
| 中间插入/删除 | `O(n)` | 不适用 | 不适用 | `O(n)` |
| 按键新增/更新/删除 | 不适用 | 平均 `O(1)` | 平均 `O(1)` | 不适用 |
| 遍历 | `O(n)` | `O(n)` | `O(n)` | `O(n)` |
| 浅拷贝 | `O(n)` | `O(n)` | `O(n)` | `O(n)` |
| 排序 | `O(n log n)` | 先取元素再排序 | 先取元素再排序 | 先取元素再排序 |

重要结论：

- 列表随机访问快，但中间插入删除需要移动元素。
- 字典、集合的平均查找快，但最坏情况不是严格 `O(1)`，且每个元素有额外内存成本。
- 不要为几十个元素过度设计；可读性和业务语义优先。
- 选择容器不能只看单次操作，还要考虑构建成本、遍历次数与内存。

## 14. `collections` 专用容器

### 14.1 `deque`：双端队列

```python
from collections import deque

queue: deque[str] = deque()
queue.append("task-1")
queue.append("task-2")
current = queue.popleft()

recent = deque(maxlen=100)
recent.append("event")
```

`maxlen` 固定长度满后，从另一端自动淘汰旧元素，适合最近记录窗口。

### 14.2 `Counter`：频率统计

```python
from collections import Counter

counter = Counter("banana")
print(counter["a"])               # 3
print(counter["missing"])         # 0
print(counter.most_common(2))      # [('a', 3), ('n', 2)]
```

`Counter` 是字典子类，支持加、减、交、并等多重集合运算。计数为零或负数的元素可能仍保留在映射中，可用一元 `+counter` 过滤非正计数。

### 14.3 `defaultdict`：按工厂创建默认值

```python
from collections import defaultdict

groups: defaultdict[str, list[str]] = defaultdict(list)

for name, department in records:
    groups[department].append(name)
```

读取不存在的键会调用默认工厂并把结果插入字典。仅仅想“读不到时返回默认值”而不改变字典，应使用普通字典的 `get()`。

### 14.4 `namedtuple`：轻量命名记录

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
point = Point(10, 20)
print(point.x, point.y)
```

新代码若需要类型标注，可优先考虑 `typing.NamedTuple`；需要默认值、校验、方法或可变字段时考虑 `dataclass`。

### 14.5 `ChainMap`：多层映射视图

```python
from collections import ChainMap

defaults = {"host": "127.0.0.1", "port": 8000}
environment = {"port": 9000}
command_line = {}

config = ChainMap(command_line, environment, defaults)
print(config["port"])  # 9000
```

查找从左到右，写入和删除默认只作用于第一个映射。它适合配置层叠，不等同于复制合并后的独立字典。

### 14.6 `OrderedDict` 还需要吗

普通 `dict` 已保证插入顺序。仍可在需要 `move_to_end()`、高效移动两端顺序，或顺序敏感相等比较时使用 `OrderedDict`。

## 15. 常见坑

### 15.1 原地方法通常返回 `None`

```python
numbers = [3, 1, 2]
result = numbers.sort()
print(result)  # None
```

需要新列表时使用 `sorted(numbers)`；需要原地修改时直接调用 `numbers.sort()`，不要链式赋值。

### 15.2 `dict.get()` 不能区分缺失与值为 `None`

```python
sentinel = object()
value = mapping.get(key, sentinel)

if value is sentinel:
    print("键不存在")
```

当 `None` 是合法值时，使用唯一哨兵或先判断 `key in mapping`。

### 15.3 遍历时改变字典或集合大小

```python
for key in list(mapping):
    if should_remove(key):
        del mapping[key]
```

也可用推导式构造新映射。更新已有键对应的值通常不改变大小，但复杂逻辑仍应避免依赖迭代中的突变。

### 15.4 集合不能保证顺序

需要保序去重时用 `dict.fromkeys()`；需要排序结果时显式 `sorted(set(items))`。

### 15.5 浅拷贝不能隔离嵌套对象

看到 `.copy()` 不要自动理解为“完全独立”。先画出或检查对象引用关系，再决定浅拷贝、深拷贝还是重新构造。

### 15.6 可变对象不能作为字典键

```python
# TypeError: unhashable type: 'list'
mapping[[1, 2]] = "value"

# 使用不可变且元素可哈希的元组
mapping[(1, 2)] = "value"
```

### 15.7 `fromkeys()` 共享可变默认值

```python
# 错误：所有键共享同一个列表
groups = dict.fromkeys(["A", "B"], [])
groups["A"].append(1)

# 正确
groups = {key: [] for key in ["A", "B"]}
```

### 15.8 文本与字节混用

```python
# TypeError
# "prefix" + b"payload"

payload = "正文".encode("utf-8")
text = payload.decode("utf-8")
```

应在系统边界完成一次明确的编码/解码，内部尽量统一使用 `str` 或 `bytes`。

### 参考实现：保序词频

```python
from collections import Counter
from string import punctuation


def count_words(text: str) -> dict[str, int]:
    words = [
        word.strip(punctuation).casefold()
        for word in text.split()
    ]
    cleaned_words = [word for word in words if word]

    counts = Counter(cleaned_words)
    return dict(counts)


print(count_words("Python, Java, python; Go!"))
```

`Counter` 作为字典子类保持首次插入顺序，因此转换为普通字典后仍按单词首次出现顺序迭代。
