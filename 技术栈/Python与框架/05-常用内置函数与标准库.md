## 1. 内置函数和标准库不是一回事

### 1.1 内置函数

内置函数由 Python 解释器直接提供，无须导入：

~~~python
names = ["Ada", "Guido", "Grace"]
print(len(names))
print(sorted(names))
~~~

`len`、`print`、`sorted` 都是内置函数。完整列表可通过 `dir(__builtins__)` 查看，但业务代码不应依赖 `__builtins__` 的具体形态。

### 1.2 标准库

标准库随 Python 一同发布，但通常需要先导入模块：

~~~python
from pathlib import Path
from datetime import datetime, timezone

print(Path.cwd())
print(datetime.now(timezone.utc))
~~~

“自带”不等于“不导入”。`pathlib`、`json`、`asyncio` 都属于标准库，而不是内置函数。

### 1.3 第三方库

第三方库由独立项目维护，需要使用 `pip`、`uv` 或其他包管理工具安装，例如 `requests`、`httpx` 和 `pydantic`。第三方库详见下一章。

## 2. 高频内置函数

### 2.1 输入、输出和对象信息

| 函数 | 典型用途 | 提醒 |
| --- | --- | --- |
| `print(*objects, sep, end, file)` | 调试、小脚本输出 | 正式服务日志使用 `logging` |
| `input(prompt)` | 读取终端一行文本 | 返回值始终是 `str`，转换时处理异常 |
| `len(obj)` | 获取容器长度 | 对迭代器通常不可用 |
| `type(obj)` | 查看对象的直接类型 | 类型判断多数优先 `isinstance` |
| `isinstance(obj, types)` | 判断继承体系中的类型 | 可传类型元组 |
| `issubclass(cls, types)` | 判断类的继承关系 | 第一个参数必须是类 |
| `id(obj)` | 当前生命周期内的对象标识 | 不代表业务 ID，也不保证跨进程稳定 |
| `help(obj)` | 交互式查看帮助 | 适合 REPL 学习 |

~~~python
raw_age = input("年龄：")
try:
    age = int(raw_age)
except ValueError:
    print("请输入整数")
else:
    print(isinstance(age, int))
~~~

不要用 `type(value) is BaseClass` 代替 `isinstance(value, BaseClass)`，前者不会接受子类实例。

### 2.2 类型转换与构造容器

常见构造器包括：

- 数值：`int`、`float`、`complex`、`bool`。
- 文本与字节：`str`、`bytes`、`bytearray`、`memoryview`。
- 容器：`list`、`tuple`、`set`、`frozenset`、`dict`。
- 序列：`range`、`slice`。

~~~python
port = int("8000")
flags = set(["read", "write", "read"])
point = tuple([10, 20])
empty_bytes = bytes(4)

print(port, flags, point, empty_bytes)
~~~

`bool` 的假值包括 `None`、数值零、空字符串和空容器。注意 `bool("False")` 仍然是 `True`，因为它是非空字符串。

### 2.3 数值与聚合

| 函数 | 示例 | 说明 |
| --- | --- | --- |
| `abs(x)` | `abs(-3) == 3` | 绝对值 |
| `round(x, ndigits)` | `round(2.675, 2)` | 受二进制浮点表示和“取偶”规则影响 |
| `pow(a, b[, mod])` | `pow(2, 10, 1000)` | 三参数形式可高效做模幂 |
| `divmod(a, b)` | `divmod(17, 5)` | 同时返回商和余数 |
| `min` / `max` | `max(rows, key=...)` | 支持 `key` 与空序列 `default` |
| `sum(items, start)` | `sum(prices)` | 拼接字符串不要用它 |

~~~python
users = [
    {"name": "Ada", "score": 96},
    {"name": "Guido", "score": 91},
]
best = max(users, key=lambda user: user["score"])
print(best)
~~~

财务小数不要依赖 `round(float)` 获得精确十进制结果，应使用 `decimal.Decimal`。

### 2.4 遍历、排序与惰性处理

| 函数 | 用途 |
| --- | --- |
| `enumerate(iterable, start=0)` | 同时取得索引与元素 |
| `zip(*iterables, strict=False)` | 并行组合多个可迭代对象 |
| `sorted(iterable, key=None, reverse=False)` | 返回新的排序列表 |
| `reversed(sequence)` | 反向迭代 |
| `all(iterable)` / `any(iterable)` | 全部满足 / 任一满足 |
| `iter(obj)` / `next(iterator, default)` | 显式使用迭代协议 |
| `map` / `filter` | 惰性映射和筛选 |

~~~python
names = ["Ada", "Grace"]
scores = [96, 98]

for index, (name, score) in enumerate(
    zip(names, scores, strict=True),
    start=1,
):
    print(index, name, score)

passed = all(score >= 60 for score in scores)
~~~

Python 3.10+ 的 `zip(..., strict=True)` 会在输入长度不一致时抛出 `ValueError`，比默认的静默截断更适合校验结构化数据。

列表推导式通常比嵌套的 `map` / `filter` 更易读：

~~~python
even_squares = [number * number for number in range(10) if number % 2 == 0]
~~~

### 2.5 文本、表示与进制

- `str` 面向用户阅读；`repr` 面向开发者诊断。
- `format(value, spec)` 与格式化字符串使用同一套格式规范。
- `ascii` 类似 `repr`，但会转义非 ASCII 字符。
- `ord` 与 `chr` 在 Unicode 码点和单字符之间转换。
- `bin`、`oct`、`hex` 生成带前缀的进制字符串。

~~~python
price = 1234.5
print(format(price, ",.2f"))
print(f"{price:,.2f}")
print(ord("中"), chr(20013))
print(bin(10), oct(10), hex(10))
~~~

### 2.6 属性、反射和可调用对象

`getattr`、`setattr`、`hasattr`、`delattr`、`dir`、`vars` 和 `callable` 可用于框架适配、插件发现或调试。

~~~python
class Config:
    timeout = 3

config = Config()
timeout = getattr(config, "timeout", 5)

if callable(getattr(config, "reload", None)):
    config.reload()
~~~

反射会降低静态可读性。普通业务逻辑能够直接访问属性时，不要为了“灵活”滥用 `getattr`。来自用户的属性名还需要白名单校验。

### 2.7 类相关内置工具

| 工具 | 作用 |
| --- | --- |
| `object` | 所有新式类的基类 |
| `super` | 按方法解析顺序调用父类实现 |
| `property` | 将方法暴露为受控属性 |
| `classmethod` | 接收类 `cls`，常用于替代构造器 |
| `staticmethod` | 放置与实例和类状态无关的辅助函数 |

~~~python
class Celsius:
    def __init__(self, value: float) -> None:
        self.value = value

    @property
    def fahrenheit(self) -> float:
        return self.value * 9 / 5 + 32

    @classmethod
    def from_fahrenheit(cls, value: float) -> "Celsius":
        return cls((value - 32) * 5 / 9)
~~~

### 2.8 文件、作用域与动态执行

- `open` 用于打开文件，推荐始终放在 `with` 中并显式指定文本编码。
- `globals` 和 `locals` 返回当前命名空间映射，常用于调试，不宜作为日常数据容器。
- `compile`、`eval`、`exec` 能动态编译或执行代码，不能接收不可信输入。
- `breakpoint` 默认进入调试器，生产代码提交前应清理临时断点。

~~~python
with open("example.txt", "w", encoding="utf-8", newline="\n") as file:
    file.write("你好，Python\n")
~~~

`eval` 不是通用数据解析器。解析 JSON 使用 `json.loads`；解析 Python 字面量也只应在理解边界后考虑 `ast.literal_eval`。

## 3. 文件、路径与运行环境

### 3.1 `pathlib`：优先使用面向对象的路径

`Path` 能组合路径、读取文件、遍历目录和查询元数据，通常比手工拼接字符串更清晰。

~~~python
from pathlib import Path

data_dir = Path("data")
data_dir.mkdir(parents=True, exist_ok=True)

config_path = data_dir / "config.json"
config_path.write_text('{"debug": true}\n', encoding="utf-8")

for path in data_dir.glob("*.json"):
    print(path.name, path.stat().st_size)

content = config_path.read_text(encoding="utf-8")
~~~

注意：

- `Path.resolve()` 用于得到规范化绝对路径，但访问前仍应考虑链接和竞态。
- 接收用户提供的相对路径时，应解析后验证仍位于允许目录内，防止 `../` 路径穿越。
- 大文件不要一次性 `read_text`，应使用 `open` 逐行或分块读取。
- 删除文件前使用 `is_file` 并不能完全消除检查与删除之间的竞态；高风险场景需要更严格的权限与文件描述符策略。

### 3.2 `os`：环境变量和操作系统接口

`os` 适合处理环境变量、进程信息、文件描述符和少量平台接口。路径操作优先 `pathlib`。

~~~python
import os

database_url = os.environ.get("DATABASE_URL")
workers = int(os.getenv("WORKERS", "4"))

print(os.name)
print(os.getpid())
~~~

`os.environ["NAME"]` 在变量缺失时抛 `KeyError`，适合强制必填；`os.getenv` 适合有合理默认值的配置。密钥不应写入日志。

### 3.3 `shutil`：高层文件操作

~~~python
from pathlib import Path
import shutil

source = Path("reports")
backup = Path("backup/reports")

shutil.copytree(source, backup, dirs_exist_ok=True)
usage = shutil.disk_usage(backup)
print(usage.free)
~~~

常见 API：

- `copy2` 尽量保留元数据；`copyfile` 只复制内容。
- `copytree` 复制目录树。
- `move` 移动文件或目录。
- `rmtree` 递归删除目录，具有破坏性，必须先解析并验证目标。
- `make_archive` / `unpack_archive` 创建或解压归档。

解压来自外部的归档前要考虑路径穿越、符号链接、压缩炸弹和磁盘配额，不能只看扩展名。

### 3.4 `sys`：解释器和进程级信息

~~~python
import sys

print(sys.version_info)
print(sys.platform)
print(sys.executable)

if sys.version_info < (3, 10):
    raise RuntimeError("需要 Python 3.10+")
~~~

- `sys.argv` 是原始命令行参数；复杂 CLI 使用 `argparse`。
- `sys.stdin`、`sys.stdout`、`sys.stderr` 是标准流。
- `sys.exit(code)` 通过抛出 `SystemExit` 结束程序。
- 不要在应用代码中随意修改 `sys.path`；应正确安装包或配置项目结构。

### 3.5 `subprocess`：调用外部程序

~~~python
import subprocess

result = subprocess.run(
    ["python", "--version"],
    check=True,
    capture_output=True,
    text=True,
    encoding="utf-8",
    timeout=10,
)
print(result.stdout or result.stderr)
~~~

推荐传“参数列表”并保持 `shell=False`。只有明确需要 shell 语法时才考虑 `shell=True`，且绝不能把未经校验的用户输入拼进命令字符串。还应设置超时、检查退出码并限制输出量。

## 4. 结构化数据与文本处理

### 4.1 `json`：跨语言数据交换

~~~python
import json
from pathlib import Path

payload = {
    "name": "景旭",
    "skills": ["Python", "FastAPI"],
    "active": True,
}

path = Path("profile.json")
with path.open("w", encoding="utf-8") as file:
    json.dump(payload, file, ensure_ascii=False, indent=2)

with path.open(encoding="utf-8") as file:
    loaded = json.load(file)
~~~

- `dump` / `load` 面向文件，`dumps` / `loads` 面向字符串。
- JSON 原生只支持对象、数组、字符串、数值、布尔和 `null`；日期与 `Decimal` 需要明确编码策略。
- `json.loads` 不会执行代码，但超大或深层数据仍可能消耗大量 CPU 和内存，应限制请求体大小。
- 不要用正则解析 JSON。

### 4.2 `csv`：表格文本

~~~python
import csv
from pathlib import Path

path = Path("users.csv")
with path.open("w", encoding="utf-8-sig", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "score"])
    writer.writeheader()
    writer.writerow({"name": "Ada", "score": 96})

with path.open(encoding="utf-8-sig", newline="") as file:
    for row in csv.DictReader(file):
        print(row["name"], int(row["score"]))
~~~

使用 `csv` 时文件应传 `newline=""`，让模块正确处理换行。`utf-8-sig` 可改善部分 Excel 场景兼容性，纯服务间交换通常使用 `utf-8`。

如果 CSV 会被电子表格打开，用户输入以 `=`、`+`、`-` 或 `@` 开头时可能触发公式注入；导出层应根据业务策略转义。

### 4.3 `re`：正则表达式

~~~python
import re

EMAIL = re.compile(r"^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$")

def looks_like_email(value: str) -> bool:
    return EMAIL.fullmatch(value) is not None
~~~

核心 API：

- `re.search` 在任意位置查找；`re.match` 只从开头匹配。
- `re.fullmatch` 要求整个字符串匹配，适合格式校验。
- `re.findall` 返回所有匹配；`re.finditer` 惰性返回匹配对象。
- `re.sub` 替换；`re.split` 拆分。
- 复杂表达式先用 `re.compile` 命名并复用。

模式通常写成原始字符串 `r"\d+"`，避免 Python 字符串转义与正则转义混在一起。不要把用户输入直接拼进模式，应使用 `re.escape`。灾难性回溯会造成 ReDoS，外部输入还应设置长度限制并简化嵌套量词。

## 5. 日期、时间与时区

### 5.1 `datetime`：区分朴素时间和感知时间

~~~python
from datetime import datetime, timedelta, timezone

now_utc = datetime.now(timezone.utc)
expires_at = now_utc + timedelta(minutes=30)

text = now_utc.isoformat()
parsed = datetime.fromisoformat(text)

assert parsed.tzinfo is not None
~~~

- “朴素” `datetime` 的 `tzinfo is None`，含义依赖上下文。
- “感知” `datetime` 带时区信息，适合跨系统传输和比较。
- 服务内部通常统一存 UTC；仅在展示或按当地规则计算时转换时区。
- `datetime.utcnow()` 返回朴素 UTC 时间，容易被误当成本地时间；优先 `datetime.now(timezone.utc)`。

### 5.2 `zoneinfo`：IANA 时区规则

~~~python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

beijing = ZoneInfo("Asia/Shanghai")
meeting_utc = datetime(2026, 8, 13, 2, 0, tzinfo=timezone.utc)
meeting_local = meeting_utc.astimezone(beijing)

print(meeting_local.isoformat())
~~~

不要用固定 `timedelta(hours=8)` 模拟有夏令时的地区。`ZoneInfo("America/New_York")` 会依据时区数据库处理历史规则和夏令时。

Windows 或精简容器可能没有系统 IANA 数据。应用可将第三方 `tzdata` 声明为依赖，`zoneinfo` 会回退使用它。

### 5.3 时间的三个概念

| 需求 | 建议 |
| --- | --- |
| 记录业务发生时刻 | 感知 UTC `datetime` |
| 向用户展示当地时间 | UTC 转 `ZoneInfo` |
| 测量耗时 | `time.monotonic()` / `time.perf_counter()` |
| 暂停当前同步线程 | `time.sleep()` |
| 暂停异步任务 | `await asyncio.sleep()` |

系统时钟可能被校准，因此测量耗时不要用两个 `datetime.now()` 相减。

## 6. 数值计算与随机数

### 6.1 `math`

`math` 提供标量数学函数和常量：

~~~python
import math

distance = math.hypot(3, 4)
pages = math.ceil(101 / 20)
close = math.isclose(0.1 + 0.2, 0.3, rel_tol=1e-9, abs_tol=0.0)

print(distance, pages, close, math.pi)
~~~

浮点比较不要直接依赖 `==`，根据业务选择 `math.isclose` 的相对和绝对容差。

### 6.2 `statistics`

~~~python
from statistics import mean, median, pstdev

latencies = [10, 12, 12, 15, 40]
print(mean(latencies))
print(median(latencies))
print(pstdev(latencies))
~~~

`statistics` 适合小规模、纯 Python 描述性统计。大规模向量计算与数据分析使用 NumPy / Pandas。

### 6.3 `random` 与 `secrets`

~~~python
import random
import secrets

sample = random.sample(range(100), k=5)
random.shuffle(sample)

reset_token = secrets.token_urlsafe(32)
verification_code = f"{secrets.randbelow(1_000_000):06d}"
~~~

- `random` 是可复现的伪随机数生成器，适合模拟、抽样、测试数据和游戏。
- `secrets` 使用操作系统提供的安全随机源，适合令牌、验证码和临时密码。
- 不要用 `random.seed(current_time)` 生成安全令牌。
- 测试中固定 `random.seed` 可提高复现性，但不要污染其他测试的全局随机状态；可创建 `random.Random(seed)` 实例。

### 6.4 `decimal`：精确十进制

~~~python
from decimal import Decimal, ROUND_HALF_UP, localcontext

price = Decimal("19.90")
quantity = Decimal("3")
total = price * quantity

with localcontext() as context:
    context.rounding = ROUND_HALF_UP
    displayed = total.quantize(Decimal("0.01"))

print(displayed)
~~~

应从字符串构造 `Decimal`。`Decimal(0.1)` 会把二进制浮点误差带进来。精度和舍入规则是业务规则的一部分，金额还应明确币种和最小单位。

### 6.5 `fractions`：有理数

~~~python
from fractions import Fraction

ratio = Fraction(1, 3) + Fraction(1, 6)
print(ratio)
print(ratio.limit_denominator())
~~~

`Fraction` 适合比例、教学和需要精确分数的运算，不适合替代所有浮点或高性能数值计算。

## 7. 容器、迭代器与函数工具

### 7.1 `collections`

| 类型 | 场景 |
| --- | --- |
| `Counter` | 频次统计、多重集合 |
| `defaultdict` | 按键自动创建默认容器 |
| `deque` | 两端高效插入删除、队列、滑动窗口 |
| `namedtuple` | 轻量不可变记录；复杂模型可选 `dataclass` |
| `ChainMap` | 多层映射的组合视图；写入和删除默认只作用于第一个映射 |

~~~python
from collections import Counter, defaultdict, deque

counts = Counter("abracadabra")
print(counts.most_common(3))

groups: defaultdict[str, list[str]] = defaultdict(list)
groups["backend"].append("FastAPI")

queue = deque(["task-1"])
queue.append("task-2")
current = queue.popleft()
~~~

普通 `list.pop(0)` 需要移动后续元素；FIFO 队列优先 `deque.popleft`。线程或异步任务之间通信则使用 `queue.Queue` 或 `asyncio.Queue`。

### 7.2 `itertools`

`itertools` 组合惰性迭代器，适合流水线式处理：

~~~python
from itertools import chain, islice, pairwise

pages = [["a", "b"], ["c"], ["d", "e"]]
first_three = list(islice(chain.from_iterable(pages), 3))
edges = list(pairwise([10, 20, 35]))

print(first_three)
print(edges)
~~~

常用工具：

- 无限迭代：`count`、`cycle`、`repeat`，务必用条件或 `islice` 截断。
- 组合：`chain`、`zip_longest`。
- 筛选与切片：`compress`、`dropwhile`、`takewhile`、`islice`。
- 分组：`groupby` 只对相邻同键元素分组，通常要先按同一键排序。
- 组合数学：`product`、`permutations`、`combinations`，结果数量可能爆炸。

### 7.3 `functools`

~~~python
from functools import cache, partial, wraps

@cache
def fibonacci(number: int) -> int:
    if number < 2:
        return number
    return fibonacci(number - 1) + fibonacci(number - 2)

def multiply(a: int, b: int) -> int:
    return a * b

double = partial(multiply, 2)
~~~

- `cache` 是无上限缓存；输入种类无界或结果很大时使用 `lru_cache(maxsize=...)`。
- 缓存的参数必须可哈希；缓存实例方法时还会持有实例引用。
- 装饰器使用 `wraps` 保留函数名、文档和签名元数据。
- `partial` 预先绑定部分参数。
- `reduce` 能累积序列，但简单求和、连接和逻辑判断优先专用函数。

### 7.4 `heapq`：堆与 Top-K

~~~python
import heapq

scores = [12, 90, 33, 72, 61]
top_three = heapq.nlargest(3, scores)

heap: list[tuple[int, str]] = []
heapq.heappush(heap, (2, "normal"))
heapq.heappush(heap, (1, "urgent"))
priority, task = heapq.heappop(heap)
~~~

`heapq` 维护最小堆。元素为元组时会逐项比较；优先级相同时，如果任务对象不可比较，应加入唯一序号作为第二项。

### 7.5 `bisect`：有序列表二分

~~~python
from bisect import bisect_left, insort

values = [10, 20, 30]
position = bisect_left(values, 25)
insort(values, 25)

print(position, values)
~~~

查找是 O(log n)，但列表中间插入仍是 O(n)。大量动态插入或复杂范围查询应考虑数据库、堆或专用数据结构。

## 8. 工程与命令行工具

### 8.1 `logging`：可分级、可配置的日志

~~~python
import logging

logger = logging.getLogger(__name__)

def load_user(user_id: int) -> None:
    logger.info("loading user id=%s", user_id)
    try:
        raise RuntimeError("demo")
    except RuntimeError:
        logger.exception("failed to load user id=%s", user_id)
~~~

应用入口统一配置日志，库模块只获取命名 logger。推荐参数化日志 `logger.info("id=%s", value)`，避免在日志级别被过滤前就构造字符串。

不要记录密码、令牌、完整身份证号等敏感数据。`logger.exception` 应在异常处理块中使用，它会附带堆栈。

### 8.2 `argparse`：无需依赖的 CLI

~~~python
import argparse

parser = argparse.ArgumentParser(description="批量导入用户")
parser.add_argument("path", help="CSV 文件路径")
parser.add_argument("--dry-run", action="store_true", help="只校验，不写入")
parser.add_argument("--workers", type=int, default=4)
args = parser.parse_args()

print(args.path, args.dry_run, args.workers)
~~~

简单运维脚本首选 `argparse`；需要类型驱动的多层命令和精美帮助时可选 Typer。

### 8.3 `tempfile`：自动清理临时资源

~~~python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as directory:
    path = Path(directory) / "result.txt"
    path.write_text("temporary", encoding="utf-8")
    print(path.read_text(encoding="utf-8"))
~~~

不要自行用可预测文件名放进公共临时目录。`NamedTemporaryFile`、`TemporaryFile` 和 `TemporaryDirectory` 能安全创建临时资源并配合上下文管理器清理。

### 8.4 `hashlib`：内容摘要

~~~python
import hashlib
from pathlib import Path

def sha256_file(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as file:
        for chunk in iter(lambda: file.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()
~~~

摘要可用于内容完整性、去重和缓存键，但裸 `SHA-256` 不是密码哈希。密码存储使用 Argon2id、bcrypt 或 scrypt 等专用方案，并由成熟密码库完成加盐和参数管理。验证消息真实性需要 HMAC 或数字签名，不能只比较普通摘要。

### 8.5 `uuid`：分布式唯一标识

~~~python
from uuid import UUID, uuid4

identifier = uuid4()
same_identifier = UUID(str(identifier))
print(identifier, same_identifier)
~~~

`uuid4` 适合生成难碰撞标识，但“难猜”不等于访问授权，也不应代替安全令牌。把 UUID 放入数据库前应优先使用数据库原生 UUID 类型，而不是无必要地存为长字符串。

## 10. 安全与正确性避坑

### 10.1 不可信数据禁止 `pickle.loads`

`pickle` 能还原 Python 对象，也可能在反序列化过程中执行任意代码。只要数据可能被用户、网络、共享存储或其他系统修改，就不要反序列化它。

替代思路：

- 普通数据交换使用 JSON。
- 复杂结构先用 JSON / MessagePack 等数据格式，再用 Pydantic 做结构校验。
- 即使数据带签名，也要考虑密钥泄露、重放和长期存储风险。

### 10.2 不可信文本禁止 `eval` / `exec`

错误示例：

~~~python
# 危险：输入可执行任意 Python 代码
result = eval(user_input)
~~~

根据意图选择解析器：

- JSON：`json.loads`。
- 整数和小数：`int`、`Decimal`。
- 日期：`datetime.fromisoformat` 或显式 `strptime`。
- 受限 Python 字面量：理解格式边界后使用 `ast.literal_eval`，同时限制输入大小。

### 10.3 `random` 不是密码学随机数

验证码、重置链接、会话令牌必须使用 `secrets`。UUID 也不应被当作权限校验。

### 10.4 时间必须明确时区

- API 中优先传 ISO 8601 感知时间，例如 `2026-08-13T10:00:00+08:00`。
- 数据库存 UTC，并保留业务所需的原始时区标识。
- 对夏令时切换附近的“当地墙上时间”，要处理不存在或重复的时间。
- 不要把服务器本地时区当作业务时区。

### 10.5 编码必须显式

- 文本文件优先 `encoding="utf-8"`。
- CSV 与 Windows/Excel 交互时再有意识地选择 `utf-8-sig`。
- 网络协议遵循协议头和规范，不能一律猜 UTF-8。
- `errors="ignore"` 会静默丢数据，不应作为默认修复方案。

### 10.6 外部进程、路径和正则要设边界

- `subprocess.run` 传参数列表、`check=True`、`timeout=...`，避免 `shell=True`。
- 用户路径解析后必须验证位于允许根目录。
- 上传文件不能只信文件名与 MIME 类型，还要限制大小并检查实际内容。
- 正则校验前限制输入长度，避免高复杂度模式。
