# React 快速上手指南：从 Vue 思维迁移到 React

> 适合：有一些 Vue 基础，希望快速掌握 React 并能够阅读、编写 React 项目的人。  
> 示例以 **React + TypeScript + 函数组件 + Hooks** 为主。React 官方目前仍推荐新代码优先使用函数组件，而不是 Class Component。citeturn553073search19

---

# 1. 先建立 React 的整体认识

如果已经学过 Vue，React 并不算完全陌生。

可以先建立下面这套对应关系：

| Vue | React |
|---|---|
| `.vue` 单文件组件 | `.tsx` / `.jsx` 组件 |
| `<template>` | JSX |
| `ref()` / `reactive()` | `useState()` |
| `props` | `props` |
| `emit` | 父组件传函数 |
| `v-if` | JS 条件判断 |
| `v-for` | `map()` |
| `v-model` | `value + onChange` |
| `computed` | 普通变量 / `useMemo` |
| `watch` | **不能简单等价为 `useEffect`** |
| `onMounted` | 常见写法为 `useEffect(..., [])` |
| `provide / inject` | Context |
| composable | Custom Hook |
| Pinia | Zustand / Redux 等 |
| Vue Router | React Router |

最大的变化其实不是 API，而是：

> **React 更强调 JavaScript 本身。**

Vue：

```vue
<template>
  <div v-if="show">
    {{ message }}
  </div>
</template>
```

React：

```tsx
function App() {
  const show = true
  const message = "Hello React"

  return (
    <div>
      {show && <div>{message}</div>}
    </div>
  )
}
```

React 没有专门设计 `v-if`、`v-for` 这一套模板指令。

而是：

```text
JavaScript
    ↓
计算 JSX
    ↓
React 渲染 UI
```

这是从 Vue 迁移 React 时最重要的思维变化。

# 3. React 组件

Vue 中：

```vue
<script setup>
const message = 'Hello'
</script>

<template>
  <div>{{ message }}</div>
</template>
```

React：

```tsx
function App() {
  const message = "Hello"

  return (
    <div>{message}</div>
  )
}

export default App
```

React 函数组件本质上就是：

```text
一个 JavaScript / TypeScript 函数
```

例如：

```tsx
function UserCard() {
  return (
    <div>
      <h2>张三</h2>
      <p>Java Developer</p>
    </div>
  )
}
```

使用组件：

```tsx
function App() {
  return (
    <div>
      <UserCard />
      <UserCard />
    </div>
  )
}
```

React 组件名称必须：

```text
大写字母开头
```

比如：

```tsx
UserCard
UserList
LoginPage
```

不要写：

```tsx
userCard
```

# 4. JSX 是什么

JSX 可以理解为：

> 在 JavaScript 中写类似 HTML 的 UI 描述。

例如：

```tsx
const name = "Tom"

return (
  <div>
    <h1>Hello {name}</h1>
  </div>
)
```

`{}` 中可以放 JavaScript 表达式：

```tsx
const age = 20

return (
  <div>
    <p>{age}</p>
    <p>{age + 1}</p>
    <p>{age >= 18 ? "成年人" : "未成年人"}</p>
  </div>
)
```

# 5. JSX 和 Vue Template 的区别

Vue：

```vue
<p class="title">Hello</p>
```

React：

```tsx
<p className="title">Hello</p>
```

注意：

```text
class → className
```

因为 `class` 本身是 JavaScript 关键字。

---

## JSX 必须有一个根节点

错误：

```tsx
return (
  <h1>Hello</h1>
  <p>React</p>
)
```

正确：

```tsx
return (
  <div>
    <h1>Hello</h1>
    <p>React</p>
  </div>
)
```

或者使用 Fragment：

```tsx
return (
  <>
    <h1>Hello</h1>
    <p>React</p>
  </>
)
```

这个：

```tsx
<>
</>
```

可以理解为 Vue 中的：

```vue
<template>
</template>
```

但不会生成额外 DOM。

# 6. Props：父组件给子组件传数据

Vue：

```vue
<UserCard :name="username" />
```

React：

```tsx
<UserCard name={username} />
```

定义子组件：

```tsx
interface UserCardProps {
  name: string
  age: number
}

function UserCard(props: UserCardProps) {
  return (
    <div>
      <p>姓名：{props.name}</p>
      <p>年龄：{props.age}</p>
    </div>
  )
}
```

使用：

```tsx
function App() {
  return (
    <UserCard
      name="张三"
      age={20}
    />
  )
}
```

更加常见的是直接解构：

```tsx
function UserCard({ name, age }: UserCardProps) {
  return (
    <div>
      <p>{name}</p>
      <p>{age}</p>
    </div>
  )
}
```

所以可以理解为：

```text
Vue props
≈
React 函数参数
```

# 7. State：组件内部状态

Vue Composition API：

```ts
const count = ref(0)
```

修改：

```ts
count.value++
```

React：

```tsx
import { useState } from "react"

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>{count}</div>
  )
}
```

`useState` 是 React 中最核心的 Hook 之一，用来给组件增加需要在多次 render 之间保存的状态。citeturn553073search11turn553073search13

这一行：

```tsx
const [count, setCount] = useState(0)
```

可以拆开理解：

```text
count
↓
当前值

setCount
↓
修改 count 的函数

0
↓
初始值
```

修改：

```tsx
setCount(count + 1)
```

完整：

```tsx
import { useState } from "react"

function Counter() {
  const [count, setCount] = useState(0)

  function add() {
    setCount(count + 1)
  }

  return (
    <div>
      <p>{count}</p>

      <button onClick={add}>
        +1
      </button>
    </div>
  )
}

export default Counter
```

# 8. React 一个非常重要的思想：State 改变 → 重新 Render

假设：

```tsx
const [count, setCount] = useState(0)
```

调用：

```tsx
setCount(1)
```

可以粗略理解为：

```text
setCount()

↓

状态发生变化

↓

React 再调用一次组件函数

↓

根据最新状态计算 JSX

↓

更新页面
```

例如：

```tsx
function Counter() {

  const [count, setCount] = useState(0)

  console.log("Counter render")

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  )
}
```

点击按钮以后：

```text
状态更新
↓
Counter()
重新执行
↓
生成新的 JSX
↓
React 更新 UI
```

所以 React 组件函数：

```tsx
function Counter() {

}
```

并不是只执行一次。

# 9. React State 不要直接修改

Vue：

```ts
const user = reactive({
  name: "Tom"
})

user.name = "Jack"
```

Vue 的响应式系统允许这种写法。

React 不推荐：

```tsx
const [user, setUser] = useState({
  name: "Tom"
})

user.name = "Jack"
```

应该创建新对象：

```tsx
setUser({
  ...user,
  name: "Jack"
})
```

例如：

```tsx
const [user, setUser] = useState({
  name: "Tom",
  age: 20
})

function changeName() {
  setUser({
    ...user,
    name: "Jack"
  })
}
```

记住：

```text
Vue：

修改响应式对象

React：

创建新的 State
```

# 10. 数组 State

例如用户列表：

```tsx
const [users, setUsers] = useState<string[]>([])
```

添加：

```tsx
setUsers([
  ...users,
  "Tom"
])
```

不要：

```tsx
users.push("Tom")
```

删除：

```tsx
setUsers(
  users.filter(user => user !== "Tom")
)
```

修改：

```tsx
setUsers(
  users.map(user =>
    user === "Tom"
      ? "Jack"
      : user
  )
)
```

这几个数组函数在 React 里面非常重要：

```text
map
filter
find
some
```

# 11. 事件绑定

Vue：

```vue
<button @click="add">
  +1
</button>
```

React：

```tsx
<button onClick={add}>
  +1
</button>
```

定义：

```tsx
function add() {
  setCount(count + 1)
}
```

也可以：

```tsx
<button
  onClick={() => setCount(count + 1)}
>
  +1
</button>
```

注意：

错误：

```tsx
<button onClick={add()}>
```

这代表：

```text
立即执行 add()
```

正确：

```tsx
<button onClick={add}>
```

代表：

```text
点击以后调用 add
```

# 12. 条件渲染：对应 v-if

Vue：

```vue
<div v-if="isLogin">
  欢迎回来
</div>
```

React 可以直接使用 JavaScript。

## 方法一：&&

```tsx
{isLogin && (
  <div>欢迎回来</div>
)}
```

## 方法二：三元表达式

```tsx
{isLogin
  ? <div>欢迎回来</div>
  : <div>请登录</div>
}
```

## 方法三：提前 return

```tsx
function UserPage() {

  if (!isLogin) {
    return <LoginPage />
  }

  return <UserProfile />
}
```

这种写法在真实 React 项目中非常常见。

# 13. 列表渲染：对应 v-for

Vue：

```vue
<li
  v-for="user in users"
  :key="user.id"
>
  {{ user.name }}
</li>
```

React：

```tsx
{users.map(user => (
  <li key={user.id}>
    {user.name}
  </li>
))}
```

完整示例：

```tsx
interface User {
  id: number
  name: string
}

function UserList() {

  const users: User[] = [
    {
      id: 1,
      name: "Tom"
    },
    {
      id: 2,
      name: "Jack"
    }
  ]

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>
          {user.name}
        </li>
      ))}
    </ul>
  )
}
```

所以：

```text
Vue v-for
↓
React Array.map()
```

这也是为什么 React 开发中 `map()` 使用频率特别高。

# 14. key 和 Vue 基本一样

Vue：

```vue
v-for="item in list"
:key="item.id"
```

React：

```tsx
list.map(item => (
  <div key={item.id}>
    {item.name}
  </div>
))
```

尽量使用稳定的业务 ID：

```tsx
key={user.id}
```

而不是：

```tsx
key={index}
```

# 15. React 表单：理解 v-model

这是 Vue 转 React 时非常重要的一点。

Vue：

```vue
<input v-model="username" />
```

React 没有直接对应的 `v-model`。

React 写法：

```tsx
const [username, setUsername] = useState("")

return (
  <input
    value={username}
    onChange={event => {
      setUsername(event.target.value)
    }}
  />
)
```

实际上就是：

```text
value
+
onChange
```

也就是所谓：

> Controlled Component（受控组件）

完整示例：

```tsx
import { useState } from "react"

function LoginForm() {

  const [username, setUsername] = useState("")
  const [password, setPassword] = useState("")

  function login() {
    console.log(username)
    console.log(password)
  }

  return (
    <div>

      <input
        value={username}
        onChange={event =>
          setUsername(event.target.value)
        }
        placeholder="用户名"
      />

      <input
        value={password}
        onChange={event =>
          setPassword(event.target.value)
        }
        placeholder="密码"
      />

      <button onClick={login}>
        登录
      </button>

    </div>
  )
}
```

Vue 给你：

```text
v-model
```

React 更喜欢把：

```text
数据从哪里来
数据怎么改变
```

明确写出来。

# 16. 子组件通知父组件：React 没有 emit

Vue：

```vue
emit("delete", id)
```

React 的思想非常简单：

> 父组件把一个函数传给子组件。

父组件：

```tsx
function App() {

  function handleDelete(id: number) {
    console.log("删除", id)
  }

  return (
    <UserItem
      id={1}
      onDelete={handleDelete}
    />
  )
}
```

子组件：

```tsx
interface Props {
  id: number
  onDelete: (id: number) => void
}

function UserItem({
  id,
  onDelete
}: Props) {

  return (
    <button
      onClick={() => onDelete(id)}
    >
      删除
    </button>
  )
}
```

数据流：

```text
父组件

 ↓ props

子组件

 ↓ 调用父组件传来的函数

父组件
```

因此：

```text
Vue emit

≈

React callback props
```

# 17. React 的数据流：单向数据流

这是 React 很核心的设计。

通常：

```text
父组件
   │
   │ props
   ▼
子组件
```

子组件不能直接修改父组件状态。

而是：

```text
父组件
 │
 ├── data
 │
 └── setData()
       ↓
   传给子组件
       ↓
子组件调用 setData()
```

React 官方把多个组件共享状态时，将状态移动到最近公共父组件的模式称为 **Lifting State Up**。citeturn553073search17

例如：

```tsx
function App() {

  const [count, setCount] = useState(0)

  return (
    <>
      <CounterDisplay count={count} />

      <CounterButton
        onAdd={() => setCount(count + 1)}
      />
    </>
  )
}
```

状态实际上属于：

```text
App
```

两个子组件只是使用它。

基本语法：


> 用来让 React 组件与 React 外部系统进行同步。citeturn553073search0turn553073search10

比如：

```text
网络连接
DOM API
浏览器 API
第三方组件
定时器
订阅
```

# 19. 类似 mounted 的场景

例如：

```tsx
useEffect(() => {

  console.log("组件挂载")

```

空数组：

```tsx
[]
```

代表这个 Effect 不依赖组件中的响应式值。

很多场景下可以把它理解成：

```text

```

# 20. 监听某个变量变化

例如：

```tsx
useEffect(() => {

  console.log("keyword changed")

}, [keyword])
```

当：

```tsx
keyword
```

变化时 Effect 会重新执行。

但不要因此把所有 Vue 的：

```ts
watch()
```

机械地改成：

```tsx
useEffect()
```

React 官方特别强调：

> 如果只是根据 props 或 state 计算另一个值，并不需要 Effect。citeturn553073search4

# 21. Vue computed 在 React 怎么写

Vue：

```ts
const fullName = computed(() => {
  return firstName.value + lastName.value
})
```

React 很多时候直接写：

```tsx
const fullName =
  firstName + lastName
```

因为组件重新 render 时：

```tsx
function App() {

  const fullName =
    firstName + lastName

}
```

自然会重新计算。

不要为了同步它再写：

```tsx
useEffect(() => {
  setFullName(firstName + lastName)
}, [firstName, lastName])
```

这种冗余 State 反而容易制造 bug；React 官方建议这类派生值优先在 render 阶段直接计算。citeturn553073search4turn553073search29

# 25. Hook 有一个非常重要的规则

不能：

```tsx
if (xxx) {
  const [count, setCount] = useState(0)
}
```

也不要：

```tsx
for (...) {
  useState(...)
}
```

Hook 要放在：

```text
组件顶层
或者
自定义 Hook 顶层
```

例如：

```tsx
function App() {

  const [count, setCount] =
    useState(0)

  if (count > 10) {
    // ...
  }

}
```

React 官方明确要求 Hooks 需要无条件调用，并放在组件或其他 Hook 的顶层。citeturn553073search11

# 26. Custom Hook：对应 Vue composable

Vue：

```ts
function useUser() {

  const user = ref(null)

  function loadUser() {
    // ...
  }

  return {
    user,
    loadUser
  }
}
```

React：

```tsx
function useUser() {

  const [user, setUser] =
    useState<User | null>(null)

  function loadUser() {
    // ...
  }

  return {
    user,
    loadUser
  }
}
```

React 官方支持通过组合内置 Hooks 创建 Custom Hook，从而复用有状态逻辑。citeturn553073search32

所以如果已经使用过 Vue Composition API：

```text
Composable
     ↓
Custom Hook
```

会非常容易理解。

# 28. async / await 请求

比较推荐你熟悉这种写法：

```tsx
async function loadUsers() {

  const response =
    await fetch("/api/users")

  const data =
    await response.json()

  setUsers(data)
}
```

然后：

```tsx
useEffect(() => {

  loadUsers()

}, [])
```

# 29. 一个完整 CRUD 风格示例

假设 Java 后端返回：

```json

  {
    "id": 1,
    "name": "张三"
  },
  {
    "id": 2,
    "name": "李四"
```

React：

```tsx
import {
  useEffect,
  useState
} from "react"

interface User {

  id: number

  name: string

}

function UserPage() {

  const [users, setUsers] =
    useState<User[]>([])

  const [name, setName] =
    useState("")

  async function loadUsers() {

    const response =
      await fetch("/api/users")

    const data =
      await response.json()

    setUsers(data)

  }

  async function addUser() {

    await fetch("/api/users", {

      method: "POST",

      headers: {
        "Content-Type":
          "application/json"
      },

      body: JSON.stringify({
        name
      })

    })

    setName("")

    await loadUsers()

  }

  async function deleteUser(id: number) {

    await fetch(
      `/api/users/${id}`,
      {
        method: "DELETE"
      }
    )

    await loadUsers()

  }

  useEffect(() => {

    loadUsers()

  }, [])

  return (

    <div>

      <h1>用户管理</h1>

      <input
        value={name}
        onChange={
          event =>
            setName(
              event.target.value
            )
        }
      />

      <button
        onClick={addUser}
      >
        添加
      </button>

      <ul>

        {users.map(user => (

          <li key={user.id}>

            {user.name}

            <button
              onClick={
                () =>
                  deleteUser(
                    user.id
                  )
              }
            >
              删除
            </button>

          </li>

        ))}

      </ul>

    </div>
  )
}

export default UserPage
```

如果你能独立写出这一段，React 基础实际上已经完成相当一部分了。

# 37. Vue 开发者最容易写出的 React 坏代码

## 错误一：直接修改 State

错误：

```tsx
user.name = "Tom"
```

正确：

```tsx
setUser({
  ...user,
  name: "Tom"
})
```

---

## 错误二：把 useEffect 当 watch

不要：

```tsx
useEffect(() => {

  setFullName(
    firstName + lastName
  )

}, [
  firstName,
  lastName
])
```

直接：

```tsx
const fullName =
  firstName + lastName
```

更简单。

---

## 错误三：所有东西都存 State

不要：

```tsx
const [price, setPrice] =
  useState(10)

const [count, setCount] =
  useState(2)

const [total, setTotal] =
  useState(20)
```

`total` 完全可以：

```tsx
const total =
  price * count
```

原则：

> 能从现有 State 计算出来的数据，通常没必要再保存一份 State。

---

## 错误四：过度 useMemo / useCallback

刚开始不要看到：

```text
useMemo
useCallback
```

就到处加。

先写：

```tsx
const result =
  calculate(data)
```

真的出现性能问题，再优化。

# 41. 最小练习 Todo

如果想先花半小时熟悉语法：

```tsx
import { useState } from "react"

interface Todo {

  id: number

  text: string

}

function App() {

  const [text, setText] =
    useState("")

  const [todos, setTodos] =
    useState<Todo[]>([])

  function addTodo() {

    if (!text.trim()) {
      return
    }

    const todo: Todo = {

      id: Date.now(),

      text: text

    }

    setTodos([
      ...todos,
      todo
    ])

    setText("")

  }

  function deleteTodo(
    id: number
  ) {

    setTodos(
      todos.filter(
        todo =>
          todo.id !== id
      )
    )

  }

  return (

    <div>

      <h1>Todo List</h1>

      <input
        value={text}
        onChange={
          event =>
            setText(
              event.target.value
            )
        }
      />

      <button
        onClick={addTodo}
      >
        添加
      </button>

      <ul>

        {todos.map(todo => (

          <li key={todo.id}>

            {todo.text}

            <button
              onClick={
                () =>
                  deleteTodo(
                    todo.id
                  )
              }
            >
              删除
            </button>

          </li>

        ))}

      </ul>

    </div>
  )
}

export default App
```

把这段完全理解以后，你实际上已经覆盖：

```text

useState

事件绑定

受控表单

数组 State

```

也就是 React 最核心的一批基础知识。
