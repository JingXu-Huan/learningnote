# 😎😎😎lambda表达式

Lambda 表达式是 Java 8 引入的一种语法糖，用来简化**只有一个抽象方法的接口**（也叫**函数式接口**）的匿名类写法。它的主要作用是：让你能用更简洁的方式去传递一段**可以执行的代码**，而不是必须定义一个完整的类去实现接口。

------

### 基本语法

```java
(参数列表) -> { 方法体 }
```

- **参数列表**：可以省略类型（编译器会自动推断）。
- **->**：读作 “goes to” 或 “箭头符号”。
- **方法体**：一行语句时可以省略 `{}` 和 `return`。
