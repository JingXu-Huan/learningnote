# Java的语法糖

## lambda表达式😢🎉

`Lambda` 表达式是用来作为函数式接口的实例，**用来实现它唯一的那个抽象方法的**。

`Comparator<T>` 是一个经典的 **函数式接口(functional Interface)**，它只有一个抽象方法：

```java
int compare(T o1, T o2);
```

我们可以用 Lambda 来实现这个方法，比如按字符串长度排序：

#### 🧵 传统写法（匿名内部类）：

```java
List<String> list = Arrays.asList("apple", "banana", "kiwi");
Collections.sort(list, new Comparator<String>() {
    @Override
    public int compare(String s1, String s2) {
        return s1.length() - s2.length();
    }
});
```

#### 🎯 Lambda 写法（实现 compare 方法）：

```java
List<String> list = Arrays.asList("apple", "banana", "kiwi");
Collections.sort(list, (s1, s2) -> s1.length() - s2.length());
```

------

### 🎯 解析：

- `Comparator<String>` 是函数式接口 ✅
- 它的抽象方法是 `int compare(T o1, T o2)` ✅
- Lambda 表达式 `(s1, s2) -> s1.length() - s2.length()` 正好是 `compare` 方法的实现 ✅
