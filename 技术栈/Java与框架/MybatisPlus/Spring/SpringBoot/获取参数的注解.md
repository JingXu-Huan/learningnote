# 注解
| 注解              | 作用场景                                      | 绑定位置             | 常用属性                                                  | 示例                                                         |
| ----------------- | --------------------------------------------- | -------------------- | --------------------------------------------------------- | :----------------------------------------------------------- |
| `@RequestParam`   | 获取 URL 查询参数（query string）或表单数据   | 方法参数（简单类型） | `value`/`name`、`required`（默认 `true`）、`defaultValue` | `java<br>@GetMapping("/search")<br>public String search(@RequestParam("q") String keyword,<br>                             @RequestParam(defaultValue="1") int page) { … }<br>` |
| `@PathVariable`   | 获取 REST 风格 URL 中的占位符                 | 方法参数             | `value`/`name`、`required`（默认 `true`）                 | `java<br>@GetMapping("/user/{id}")<br>public User getUser(@PathVariable Long id) { … }<br>` |
| `@RequestBody`    | 获取 HTTP 请求体（通常是 JSON、XML、表单）    | 方法参数（复杂对象） | `required`（默认 `true`）                                 | `java<br>@PostMapping("/users")<br>public User create(@RequestBody UserDto dto) { … }<br>` |
| `@RequestHeader`  | 获取 HTTP 请求头                              | 方法参数             | `value`、`required`、`defaultValue`                       | `java<br>@GetMapping("/data")<br>public String data(@RequestHeader("X-Auth-Token") String token) { … }<br>` |
| `@CookieValue`    | 获取 Cookie 值                                | 方法参数             | `value`、`required`、`defaultValue`                       | `java<br>@GetMapping("/welcome")<br>public String welcome(@CookieValue("lang") String lang) { … }<br>` |
| `@ModelAttribute` | 绑定表单数据到 Model 对象，并可预先放入 Model | 方法参数或方法上方   | `name`                                                    | `java<br>@PostMapping("/form")<br>public String submit(@ModelAttribute UserForm form) { … }<br>` |



------

### 小提示 🐥

1. **`required=false` + `defaultValue`**
   - 当参数可选时，记得设 `required=false`，否则未传参就会报 400。
   - 若希望有默认值，还可以写 `defaultValue="xxx"`。
2. **`@RequestBody` 与消息转换器**
   - 对于 JSON、XML 等复杂类型，Spring 会借助 Jackson、FastJSON、JAXB 等自动反序列化；
   - 如果请求体为空且 `required=true`，会抛 `HttpMessageNotReadableException`。
3. **参数校验**
   - 可以结合 JSR‑303 注解（`@Valid`/`@Validated`）对 `@RequestBody` 或 `@ModelAttribute` 对象做校验，记得在配置里开启 MethodValidation。
4. **顺手用 Swagger/OpenAPI**
   - 标注了这些注解后，配合 Swagger 还能自动生成 API 文档，效率满分～

### 补充说明😎：

* 如果方法中的参数和前端传递的参数名一致，则会自动赋值。

```java
// 前端请求：GET /search?q=java&page=2
@GetMapping("/search")
public String search(String q, int page) {
    // q 和 page 会自动从请求中取值
    …
}
```
