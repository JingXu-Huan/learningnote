# Spring Boot 常用注解

> 这里整理 Spring Boot 开发中最常用的注解，按用途分类。获取请求参数的注解（@RequestParam 等）见 [[获取参数的注解]]，其它杂项注解见 [[其它注解]]。

------

## 一、组件注册注解

| 注解 | 作用 | 典型用法 |
|------|------|---------|
| `@Component` | 通用组件，交给 Spring 容器管理 | 加在类上 |
| `@Service` | 业务逻辑层（语义同 @Component） | 加在 Service 类上 |
| `@Repository` | 数据访问层（语义同 @Component） | 加在 Mapper/Dao 类上 |
| `@Controller` | Web 控制层（返回视图） | 加在 Controller 类上 |
| `@RestController` | `@Controller` + `@ResponseBody`（返回 JSON） | RESTful 接口 |
| `@Configuration` | 配置类（替代 XML） | 加在配置类上 |
| `@Bean` | 在配置类中声明一个 Bean | 方法上 |

```java
@Configuration
public class AppConfig {
    @Bean
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}
```

------

## 二、依赖注入注解

| 注解 | 作用 | 说明 |
|------|------|------|
| `@Autowired` | 按类型自动注入 | Spring 提供，默认 required=true |
| `@Qualifier` | 配合 @Autowired 指定 Bean 名称 | 解决多个同类型 Bean 的歧义 |
| `@Resource` | 按名称注入 | javax 提供，默认按名称查找 |
| `@Value` | 注入配置值 | 支持 SpEL 和 `${...}` 占位符 |

```java
@Service
public class UserService {
    @Autowired
    private UserMapper userMapper;

    @Value("${app.name}")
    private String appName;
}
```

## 三、请求映射注解

| 注解 | 作用 |
|------|------|
| `@RequestMapping` | 通用请求映射 |
| `@GetMapping` | GET 请求 |
| `@PostMapping` | POST 请求 |
| `@PutMapping` | PUT 请求 |
| `@DeleteMapping` | DELETE 请求 |
| `@PatchMapping` | PATCH 请求 |

详见 [[AOP]]。

|------|------|

## 五、事务注解

详见 [[数据库事务]]。

```java
@Transactional(rollbackFor = Exception.class)
public void transfer(Long fromId, Long toId, BigDecimal amount) {
    // 转账逻辑，任何异常都会回滚
}
```

## 六、生命周期注解

| 注解 | 作用 | 执行时机 |
|------|------|---------|
| `@PostConstruct` | Bean 初始化后执行一次 | 依赖注入完成后 |
| `@PreDestroy` | Bean 销毁前执行一次 | 容器关闭时 |

详见 [[postConstruct]]。

------

## 七、条件注解

| 注解 | 作用 |
|------|------|
| `@ConditionalOnBean` | 容器中存在某个 Bean 时生效 |
| `@ConditionalOnMissingBean` | 容器中不存在某个 Bean 时生效 |
| `@ConditionalOnProperty` | 配置属性满足条件时生效 |
| `@ConditionalOnClass` | classpath 中存在某个类时生效 |

```java
@Configuration
@ConditionalOnProperty(name = "app.cache.enabled", havingValue = "true")
public class CacheConfig {
    // 只有配置了 app.cache.enabled=true 才会加载
}
```
