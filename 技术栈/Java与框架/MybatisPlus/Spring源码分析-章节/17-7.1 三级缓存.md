# 7.1 三级缓存

Spring 单例池相关的三个缓存大致如下：

```java
singletonObjects
earlySingletonObjects
singletonFactories
```

可以理解为：

| 缓存                    | 含义                       |
| --------------------- | ------------------------ |
| singletonObjects      | 一级缓存，保存完整初始化后的单例 Bean    |
| earlySingletonObjects | 二级缓存，保存提前暴露的早期 Bean      |
| singletonFactories    | 三级缓存，保存可以创建早期 Bean 引用的工厂 |
