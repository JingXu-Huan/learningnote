读取共享变量

线程 A 先把共享变量 value 的当前值读入自己的工作内存副本。JMM 用这套抽象描述多线程读写必须遵守的可见性规则。

A: read value → working copy

看图时记住

  • JMM 的主内存 / 工作内存是并发语义模型。
  • 它不等于 JVM 堆 / 栈，也不等于 CPU 缓存的真实布局。
  • volatile 不会把 count++ 变成原子操作。
避免混淆：JMM 解决“线程如何正确观察彼此的读写”；JVM 运行时数据区说明“规范上数据逻辑归属哪里”；GC 则是 JVM 实现如何识别不可达对象并回收空间。三者相关，但并不是同一张内存布局图。
