# Go 语言从 0 到 1：渐进式学习路线（Java / Spring 开发者版）

> 不再把 Go 塞进一篇很长的笔记里。按本目录从上到下学习：**一章只解决一个问题，每章都有练习和验收。**
>
> 学习顺序：语法 → 数据结构 → 内存小项目 → REST API → MySQL → 并发 → 结业项目。

------

## 怎么使用这套笔记

1. 每次只打开当前章节，预计投入 30～90 分钟。
2. 先手写示例，再做“动手练习”，最后执行验收命令。
3. 没通过本章验收，不急着跳下一章。
4. 第 10 章结束时，你会完成一个可运行的简单小项目；第 11 章后开始进入 Go 后端实战。

每章都尽量遵循同一节奏：

~~~text
本章目标
→ 最小概念
→ 可运行代码
→ 手写练习
→ 验收与常见坑
→ 下一章
~~~

## 每章都执行的质量命令

~~~powershell
go fmt ./...
go test ./...
go vet ./...
go build ./...
~~~

涉及并发后，再加：

~~~powershell
go test -race ./...
~~~

## 工具与版本原则

- Go 从 [官方下载页](https://go.dev/dl/) 安装当前 Stable 版本，不要跟着旧教程固定版本号。
- 使用 GoLand 时，可在 <code>Ctrl + Alt + S → Go → GOROOT → Add SDK</code> 配置 SDK。
- 新项目以 <code>go.mod</code> 为中心，不需要把代码放进 <code>GOPATH/src</code>。
- 写完一段代码先运行，再继续下一段；不要只看不敲。

## Java 开发者的路线提醒

你不需要重学 HTTP、SQL、缓存、事务这些后端问题；真正要重点迁移的是：

~~~text
异常模型 → 显式 error
类继承 → struct + 组合
Spring DI → 构造函数 + main 中组装
线程池 → goroutine + Context + 有界并发
Maven → Go Modules
~~~

从 [第 01 章](01-环境搭建与第一个Go程序.md) 开始即可。
