# 01：环境搭建与第一个 Go 程序

> 预计：30～45 分钟<br>
> 本章目标：安装 Go、理解 Go Module，并亲手运行第一个程序。

------

## 1. 本章完成后，你应该能做到

- 在 PowerShell 中看到 <code>go version</code> 的输出。
- 创建一个含 <code>go.mod</code> 的 Go 项目。
- 写出并运行 <code>Hello, Go!</code>。
- 区分 <code>go run</code>、<code>go build</code> 和 <code>go test</code>。

## 2. 安装 Go

从 [Go 官方下载页](https://go.dev/dl/) 选择当前 Stable 版本的 Windows x64 MSI。版本会更新，不需要死记数字；新项目优先使用官网下载页标记的稳定版本。

安装完成后，关闭并重新打开 PowerShell，执行：

~~~powershell
go version
go env GOROOT GOPATH GOMODCACHE
go env GOOS GOARCH
~~~

如果系统提示找不到 <code>go</code>：

1. 先关闭并重新打开终端。
2. 确认 Go 已成功安装。
3. 再检查 Go 的 <code>bin</code> 目录是否已加入 PATH。

使用 GoLand 时：

~~~text
Ctrl + Alt + S
→ Go
→ GOROOT
→ Add SDK
→ Download 或 Local
~~~

不要把 <code>GOROOT</code> 当项目目录；它是 Go SDK 的安装位置。

## 3. 创建第一个 Go Module

现代 Go 项目不必放进 <code>GOPATH/src</code>。一个项目最重要的根文件是 <code>go.mod</code>，它记录模块名和依赖。

在你的代码目录执行：

~~~powershell
New-Item -ItemType Directory -Name 'go-learning'
Set-Location .\go-learning
go mod init example.com/go-learning
~~~

这里的 <code>example.com/go-learning</code> 是练习模块名。以后推送 GitHub 时，可以改成对应仓库路径，例如 <code>github.com/你的账号/项目名</code>。

## 4. 第一个程序

新建 <code>main.go</code>：

~~~go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
~~~

运行：

~~~powershell
go run .
~~~

你应该看到：

~~~text
Hello, Go!
~~~

| 代码 | 含义 |
| --- | --- |
| package main | 当前包是可执行程序入口 |
| import "fmt" | 引入格式化输出标准库 |
| func main() | 程序从这里开始执行 |
| fmt.Println | 输出一行文本 |

## 5. 第一组必会命令

~~~powershell
go run .        # 编译后立刻运行
go build .      # 编译当前程序
go test ./...   # 运行当前模块所有测试
go fmt ./...    # 统一格式化
go vet ./...    # 检查常见可疑写法
~~~

现在不需要手动配置 GOPATH，也不要手工编辑 <code>go.sum</code>。

## 6. 动手练习

把程序改成输出你的名字和学习目标：

~~~text
你好，JingXu！
我的目标是完成第一个 Go 小项目。
~~~

完成后执行：

~~~powershell
go fmt ./...
go run .
go build .
~~~

## 7. 本章验收

- [ ] <code>go version</code> 可用。
- [ ] 当前目录有 <code>go.mod</code> 和 <code>main.go</code>。
- [ ] <code>go run .</code> 可以正常输出。
- [ ] 能说出：<code>go.mod</code> 是当前项目的模块声明文件。
