# 08：小项目——内存告警管理器（需求与建模）

> 预计：45～60 分钟<br>
> 本章目标：开始第一个项目。先只定义业务数据和状态，让项目能跑起来。

------

## 1. 项目要做什么

我们先做一个不连数据库的命令行告警管理器。它最终要支持：

~~~text
创建告警
查看全部告警
处理一条告警
保存和读取 JSON 文件
~~~

先把业务模型写对，再添加 CRUD、JSON、测试；不要一开始就接 MySQL、Gin 或 Redis。

## 2. 创建项目

~~~powershell
New-Item -ItemType Directory -Name 'alert-cli'
Set-Location .\alert-cli
go mod init example.com/alert-cli

New-Item -ItemType Directory -Force '.\cmd\alert-cli'
New-Item -ItemType Directory -Force '.\internal\alert'
~~~

目录应变成：

~~~text
alert-cli/
├── cmd/alert-cli/main.go
├── internal/alert/model.go
└── go.mod
~~~

## 3. 定义告警模型

创建 <code>internal/alert/model.go</code>：

~~~go
package alert

type Status string

const (
    StatusOpen     Status = "open"
    StatusResolved Status = "resolved"
)

type Alert struct {
    ID       int64
    DeviceID string
    Level    string
    Status   Status
}

func New(deviceID string, level string) Alert {
    return Alert{
        DeviceID: deviceID,
        Level:    level,
        Status:   StatusOpen,
    }
}
~~~

这里把允许的状态集中定义为 <code>open</code> 与 <code>resolved</code>，避免字符串散落在业务代码里。注意：<code>type Status string</code> 本身不会阻止别人赋一个非法字符串；真正的状态校验应写在 Create、Resolve 等业务方法中。

## 4. 写一个能运行的入口

创建 <code>cmd/alert-cli/main.go</code>：

~~~go
package main

import (
    "fmt"

    "example.com/alert-cli/internal/alert"
)

func main() {
    item := alert.New("dorm-1-101", "high")
    fmt.Printf("%+v\n", item)
}
~~~

注意：import 中的 <code>example.com/alert-cli</code> 必须与 <code>go.mod</code> 第一行的模块名一致。

运行：

~~~powershell
go fmt ./...
go run ./cmd/alert-cli
~~~

## 5. 本章要理解的建模点

| 概念 | 这里的体现 |
| --- | --- |
| 领域对象 | Alert |
| 有限状态 | StatusOpen、StatusResolved |
| 默认值 | 新告警默认是 open |
| 程序入口 | cmd/alert-cli/main.go |
| 内部实现 | internal/alert |

## 6. 动手练习

1. 给 Alert 增加 <code>Message</code> 字段。
2. 再增加一个导出的 <code>CreatedAt time.Time</code> 字段，并把它的 JSON 字段名设为 <code>createdAt</code>；小写的 Go 字段不能被默认 JSON 编码。
3. 在 <code>New</code> 中用 <code>time.Now()</code> 自动填充创建时间。

字段写法参考：

~~~go
CreatedAt time.Time `json:"createdAt"`
~~~

同时需要在 model.go 中导入 <code>time</code>。
