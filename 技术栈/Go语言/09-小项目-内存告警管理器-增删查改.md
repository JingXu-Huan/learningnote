# 09：小项目——内存告警管理器（增删查改）

> 预计：60～90 分钟<br>
> 本章目标：用上一章学过的 slice、struct、错误和方法，实现第一个可用的小项目。

------

## 1. 这章要完成的功能

~~~text
Create：创建告警并分配 ID
Read：查询全部告警或一条告警
Update：把 open 告警处理为 resolved
Delete：删除一条告警
~~~

数据先放在内存中。程序停止后数据会消失，这是正常的；下一章再保存为 JSON。

## 2. 创建内存 Store

创建 <code>internal/alert/store.go</code>：

~~~go
package alert

import "errors"

var (
    ErrInvalidAlert   = errors.New("deviceID and level are required")
    ErrAlertNotFound  = errors.New("alert not found")
    ErrAlreadyResolved = errors.New("alert already resolved")
)

type Store struct {
    nextID int64
    alerts []Alert
}

func NewStore() *Store {
    return &Store{
        alerts: make([]Alert, 0),
    }
}

func NewStoreFromAlerts(alerts []Alert) *Store {
    copied := make([]Alert, len(alerts))
    copy(copied, alerts)

    var maxID int64
    for _, item := range copied {
        if item.ID > maxID {
            maxID = item.ID
        }
    }

    return &Store{
        nextID: maxID,
        alerts: copied,
    }
}

func (s *Store) Create(deviceID string, level string) (Alert, error) {
    if deviceID == "" || level == "" {
        return Alert{}, ErrInvalidAlert
    }

    s.nextID++
    item := New(deviceID, level)
    item.ID = s.nextID
    s.alerts = append(s.alerts, item)
    return item, nil
}

func (s *Store) List() []Alert {
    result := make([]Alert, len(s.alerts))
    copy(result, s.alerts)
    return result
}

func (s *Store) FindByID(id int64) (Alert, error) {
    for _, item := range s.alerts {
        if item.ID == id {
            return item, nil
        }
    }
    return Alert{}, ErrAlertNotFound
}

func (s *Store) Resolve(id int64) (Alert, error) {
    for i := range s.alerts {
        if s.alerts[i].ID != id {
            continue
        }
        if s.alerts[i].Status == StatusResolved {
            return Alert{}, ErrAlreadyResolved
        }

        s.alerts[i].Status = StatusResolved
        return s.alerts[i], nil
    }
    return Alert{}, ErrAlertNotFound
}

func (s *Store) Delete(id int64) error {
    for i, item := range s.alerts {
        if item.ID != id {
            continue
        }
        s.alerts = append(s.alerts[:i], s.alerts[i+1:]...)
        return nil
    }
    return ErrAlertNotFound
}
~~~

<code>List</code> 返回副本，而不是直接把内部 slice 交给调用方。这样调用方无法意外修改 Store 的内部数据。

## 3. 更新入口程序

把 <code>cmd/alert-cli/main.go</code> 替换为：

~~~go
package main

import (
    "fmt"

    "example.com/alert-cli/internal/alert"
)

func main() {
    store := alert.NewStore()

    first, err := store.Create("dorm-1-101", "high")
    if err != nil {
        panic(err)
    }

    if _, err := store.Create("library-2-203", "medium"); err != nil {
        panic(err)
    }

    if _, err := store.Resolve(first.ID); err != nil {
        panic(err)
    }

    found, err := store.FindByID(first.ID)
    if err != nil {
        panic(err)
    }
    fmt.Println("已处理：", found)

    for _, item := range store.List() {
        fmt.Printf("ID=%d device=%s level=%s status=%s\n",
            item.ID,
            item.DeviceID,
            item.Level,
            item.Status,
        )
    }
}
~~~

运行：

~~~powershell
go fmt ./...
go run ./cmd/alert-cli
~~~

这里的 panic 只为练习代码快速暴露意外失败。真实 HTTP 服务里，参数错误、记录不存在等普通业务错误要返回给调用方，而不是 panic。

## 4. 你刚刚用到了什么

| 旧知识 | 在项目中的位置 |
| --- | --- |
| struct | Alert、Store |
| 自定义类型与常量 | Status |
| slice | Store.alerts |
| 指针接收者 | Store 的 Create、Resolve |
| error | 参数非法、找不到告警、重复处理 |
| copy | List 与 NewStoreFromAlerts 返回 / 保存防御性副本 |

## 5. 动手练习

1. 在 main 中调用 <code>Delete</code>，删除指定 ID 的告警。
2. List 支持只返回 open 状态告警。
3. 从一组已有 Alert 创建 <code>NewStoreFromAlerts</code>，确认下一条 ID 不会重复。
4. 把 main 中的 panic 改为友好地打印错误并 return。

## 6. 常见坑

- 不要给 <code>range</code> 取出的副本直接赋值；需要修改 slice 元素时用索引。
- 这版 Store 还不是并发安全的；不要在多个 goroutine 中同时调用它。
- 删除 slice 元素时要特别注意下标和是否需要保留原顺序。
