# 02：变量、类型、零值与流程控制

> 预计：45～60 分钟<br>

------

## 1. 变量：为什么 Go 有 :=

~~~go
name := "JingXu"
age := 20
~~~

<code>:=</code> 是短变量声明，表示“声明新变量并赋值”。其中的 <code>:</code> 不能省略，因为：

~~~go
name = "JingXu" // 只表示给已存在的变量赋值
name := "JingXu" // 声明 name，并由编译器推断类型
~~~

完整写法是：

~~~go
var name string = "JingXu"
var age int = 20
var score float64
~~~

常用规则：

- <code>:=</code> 只能写在函数内部。
- 同一作用域中，<code>:=</code> 左侧至少要有一个新变量。
- 包级变量使用 <code>var</code>，不能使用 <code>:=</code>。

## 2. 常用基础类型与零值

| 类型 | 示例 | 零值 |
| --- | --- | --- |
| int / int64 | <code>count := 3</code> | 0 |
| float64 | <code>rate := 0.85</code> | 0 |
| string | <code>name := "Go"</code> | 空字符串 |
| bool | <code>enabled := true</code> | false |

零值不是“没有初始化”，而是 Go 为每个类型提供的默认可用值。后续处理业务状态时，要想清楚 0、空字符串和 nil 是否有真实业务含义。

## 3. 条件与循环

Go 的 <code>if</code> 不写圆括号，花括号不能省略：

~~~go
if age >= 18 {
    fmt.Println("成年人")
} else {
    fmt.Println("未成年人")
}
~~~

Go 只有 <code>for</code>，它同时承担 Java 的 <code>for</code>、<code>while</code>：

~~~go
for i := 1; i <= 3; i++ {
    fmt.Println(i)
}

sum := 0
for sum < 10 {
    sum++
}
~~~

<code>switch</code> 适合离散状态；默认不会自动穿透到下一个 case。

## 4. 最小可运行示例

把下面内容替换到 <code>main.go</code> 后运行：

~~~go
package main

import "fmt"

func main() {
    name := "JingXu"
    score := 86
    total := 0

    for i := 1; i <= 5; i++ {
        total += i
    }

    if score >= 60 {
        fmt.Println(name, "通过了考试")
    } else {
        fmt.Println(name, "需要补考")
    }

    switch {
    case score >= 90:
        fmt.Println("等级：A")
    case score >= 80:
        fmt.Println("等级：B")
    default:
        fmt.Println("等级：C")
    }

    fmt.Println("1 到 5 的和：", total)
}
~~~

## 5. Java 对照

| Java | Go |
| --- | --- |
| <code>int age = 20;</code> | <code>age := 20</code> |
| <code>final int LIMIT = 10;</code> | <code>const limit = 10</code> |
| <code>while (ok) {}</code> | <code>for ok {}</code> |
| <code>if (ok) {}</code> | <code>if ok {}</code> |

## 7. 常见坑

- 在内层 <code>if</code> 中随手用 <code>:=</code>，可能新建了同名变量，导致你以为更新了外层变量。
- 不要用 <code>float64</code> 表示金额；真实金额通常用最小货币单位的整数或高精度方案。
- <code>const</code> 适合不会变化的值，配置项通常来自环境变量，不要全写死。
