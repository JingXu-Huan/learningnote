# 19.4 从 Master 测试 node2

```bash
curl http://<NODE2_IP>:31234
```

如果两次都返回 Nginx HTML，说明：

* Tailscale 节点网络正常
* kube-proxy 正常
* Calico VXLAN 正常
* 跨节点 Pod 网络正常
* NodePort 正常

也可以自动获取 NodePort：

```bash
NODE_PORT=$(
  kubectl get svc nginx-test \
    -o jsonpath='{.spec.ports[0].nodePort}'
)

echo "$NODE_PORT"
```

然后执行：

```bash
curl "http://<NODE1_IP>:${NODE_PORT}"
curl "http://<NODE2_IP>:${NODE_PORT}"
```
