# 7.4 启动 containerd

```bash
sudo systemctl enable containerd
sudo systemctl restart containerd
```

检查：

```bash
sudo systemctl status containerd --no-pager
```

应显示：

```text
Active: active (running)
```

检查 CRI 插件：

```bash
sudo ctr plugins ls | grep cri
```

至少应该有相关插件处于 `ok` 状态。
