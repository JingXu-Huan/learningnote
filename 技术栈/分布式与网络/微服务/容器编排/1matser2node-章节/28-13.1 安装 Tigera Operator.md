# 13.1 安装 Tigera Operator

在 Master 执行：

```bash
kubectl create -f \
  https://raw.githubusercontent.com/projectcalico/calico/v3.32.1/manifests/tigera-operator.yaml
```

等待 Installation CRD 创建：

```bash
kubectl wait \
  --for=condition=Established \
  crd/installations.operator.tigera.io \
  --timeout=180s
```
