# 7.3 确认 CRI 没被禁用

检查：

```bash
grep -n "disabled_plugins" /etc/containerd/config.toml
```

如果看到：

```toml
disabled_plugins = ["cri"]
```

需要删除 `cri`：

```bash
sudo sed -i \
  's/disabled_plugins = \["cri"\]/disabled_plugins = []/' \
  /etc/containerd/config.toml
```

Kubernetes 通过 CRI 与 containerd 通信，`cri` 插件不能被禁用。
