# 5.3 测试节点互通

在 Master 上：

```bash
ping -c 4 <NODE1_IP>
ping -c 4 <NODE2_IP>
```

在 node1 上：

```bash
ping -c 4 <MASTER_IP>
ping -c 4 <NODE2_IP>
```

在 node2 上：

```bash
ping -c 4 <MASTER_IP>
ping -c 4 <NODE1_IP>
```

也可以使用 Tailscale 自带命令：

```bash
tailscale ping <对端Tailscale-IP>
```

三台机器必须全部能够相互访问。
