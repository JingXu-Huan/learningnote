## 6.1 常见地址范围

| 地址／范围 | 含义 | 注意事项 |
|---|---|---|
| 10.0.0.0/8 | 私有 IPv4 地址 | 可以在不同私有网络中重复使用 |
| 172.16.0.0/12 | 私有 IPv4 地址 | 范围为 172.16.0.0～172.31.255.255 |
| 192.168.0.0/16 | 私有 IPv4 地址 | 家庭与企业内网常见 |
| 127.0.0.0/8 | 回环地址 | 最常见是 127.0.0.1 |
| 0.0.0.0 | 未指定地址等特殊用途 | 应用监听时常表示所有本地 IPv4 接口 |
| 0.0.0.0/0 | 默认 IPv4 路由前缀 | 表示所有 IPv4 目的地址都能匹配 |
| 255.255.255.255 | 有限广播地址 | 用于本地链路广播，路由器不转发 |
| 169.254.0.0/16 | IPv4 链路本地地址 | 自动配置场景常见，不跨路由器转发 |
| 100.64.0.0/10 | 共享地址空间 | 常用于运营商 CGNAT，不属于上述三段私有地址 |
| 224.0.0.0/4 | IPv4 组播地址 | 不是普通单播主机地址 |
| 192.0.2.0/24 | 文档示例地址 | 不应拿来当实际公网服务地址 |
| 198.51.100.0/24 | 文档示例地址 | 本笔记用于示例 |
| 203.0.113.0/24 | 文档示例地址 | 本笔记用于示例 |

## 6.2 公网地址与私有地址

私有地址可以在内网中正常路由，但通常不在公共互联网中被路由。

家庭网络一般通过 NAT，让私有地址主机访问公共互联网。

**“不是私有地址”不等于“可用公网地址”。**还有回环、链路本地、文档、组播和其他特殊用途范围。

**“拥有公网地址”也不等于“外部一定能访问”。**还要满足路由可达、端口监听、防火墙允许和运营商策略等条件。
