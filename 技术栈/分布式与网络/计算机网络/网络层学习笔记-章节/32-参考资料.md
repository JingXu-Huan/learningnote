# 32. 参考资料

[返回网络层学习笔记](<../网络层学习笔记.md>)

下面列出协议原始规范，适合核对具体机制。基础学习先掌握正文，再按问题阅读对应规范即可。部分 RFC 已有更新，精确实现要求应同时查看页面中的更新与勘误。

1. [RFC 791 — Internet Protocol：IPv4 基础规范](https://www.rfc-editor.org/info/rfc791/)
2. [RFC 8200 — Internet Protocol, Version 6：IPv6 规范](https://www.rfc-editor.org/info/rfc8200/)
3. [RFC 4632 — CIDR：地址分配、聚合与最长匹配](https://www.rfc-editor.org/info/rfc4632/)
4. [RFC 3021 — IPv4 点到点链路使用 /31 前缀](https://www.rfc-editor.org/info/rfc3021/)
5. [RFC 2328 — OSPF Version 2](https://www.rfc-editor.org/info/rfc2328/)
6. [RFC 4271 — BGP-4](https://www.rfc-editor.org/info/rfc4271/)
7. [RFC 792 — ICMPv4](https://www.rfc-editor.org/info/rfc792/)
8. [RFC 4861 — IPv6 邻居发现](https://www.rfc-editor.org/info/rfc4861/)
9. [RFC 3022 — Traditional NAT](https://www.rfc-editor.org/info/rfc3022/)
10. [RFC 826 — ARP](https://www.rfc-editor.org/info/rfc826/)
11. [RFC 1918 — 私有 IPv4 地址](https://www.rfc-editor.org/info/rfc1918/)
12. [RFC 2453 — RIP Version 2](https://www.rfc-editor.org/info/rfc2453/)
13. [RFC 1191 — IPv4 路径 MTU 发现](https://www.rfc-editor.org/info/rfc1191/)
14. [IANA — IPv4 特殊用途地址登记表](https://www.iana.org/assignments/iana-ipv4-special-registry/iana-ipv4-special-registry.xhtml)
15. [RFC 1812 — IPv4 路由器要求](https://www.rfc-editor.org/info/rfc1812/)
