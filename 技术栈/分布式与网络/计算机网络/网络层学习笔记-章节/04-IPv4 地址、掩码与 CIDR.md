## 4.1 IPv4 的表示方法

IPv4 地址长 32 位，常写成 4 个十进制数，每个数表示 8 位，范围是 0～255。

例如：

```text
192.168.1.10
对应二进制：11000000.10101000.00000001.00001010
```

## 4.2 网络部分与主机部分

在常见子网模型中，IPv4 地址分为：

- 网络前缀：说明属于哪个网络。
- 主机部分：说明在这个网络中是哪一个地址。

**分界线由前缀长度／子网掩码决定，不能只看 IP 的前几个十进制数。**

例如同一个地址 `192.168.1.10`：

- `/24` 时属于 `192.168.1.0/24`。
- `/16` 时属于 `192.168.0.0/16`。

## 4.3 子网掩码

现代常见子网掩码由连续的 1 和连续的 0 构成：

- 1 对应网络部分。
- 0 对应主机部分。

```text
/24 = 11111111.11111111.11111111.00000000
    = 255.255.255.0

/26 = 11111111.11111111.11111111.11000000
    = 255.255.255.192
```

## 4.4 CIDR 记法

CIDR 即无类别域间路由。常用 `地址/前缀长度` 表示地址或地址块。

```text
192.168.1.10/24   表示一个带前缀长度的接口地址
192.168.1.0/24    表示规范写法的网络前缀
```

`/24` 表示前 24 位是网络部分，剩下 8 位是主机部分。

CIDR 的价值包括灵活分配地址、支持路由聚合、减小路由表。[3]

## 4.5 网络地址如何计算

```text
网络地址 = IP 地址 按位与 子网掩码
```

例如：

```text
IP：      192.168.1.130
掩码：    255.255.255.192，也就是 /26

最后一字节：
130 = 10000010
192 = 11000000
AND = 10000000 = 128

网络地址：192.168.1.128
```

## 4.6 传统分类编址

| 类别 | 首字节范围 | 历史默认前缀 | 主要用途 |
|---|---|---|---|
| A 类 | 1～126 | /8 | 历史单播分类 |
| B 类 | 128～191 | /16 | 历史单播分类 |
| C 类 | 192～223 | /24 | 历史单播分类 |
| D 类 | 224～239 | 无上述网络／主机划分 | 组播 |
| E 类 | 240～255 | 无上述网络／主机划分 | 保留用途，含特殊地址 |

`0/8`、`127/8` 等有特殊含义，上表仅用于理解传统分类，不能代替特殊地址规则。

**考试可能考 A/B/C 类，但实际分析地址和路由时应以显式前缀长度为准。**
