## 23.1 建议的学习顺序

1. 理解 IP 与 MAC 的职责，以及同网段／跨网段发送过程。
2. 掌握掩码、CIDR、网络地址、广播地址和主机数量。
3. 练习子网划分、VLSM 与路由聚合。
4. 理解 IPv4 首部、TTL、MTU 和分片。
5. 掌握路由表、最长前缀匹配与默认路由。
6. 理解距离向量、链路状态和 RIP／OSPF／BGP。
7. 串起 ICMP、NAT、IPv6 与常见排障现象。

## 23.2 考试常见重点

- 子网计算：网络地址、广播地址、可分配范围与数量。
- 路由表查找：最长前缀匹配。
- 路由聚合：共同前缀、对齐与额外覆盖范围。
- 分片计算：首部长度、MTU、8 字节对齐、MF 与偏移。
- 算法题：距离向量更新、Dijkstra 最短路径。
- 简答题：IP 服务模型、ARP 过程、ICMP、IPv4／IPv6 差异、协议对比。

## 23.3 面试常见重点

- 为什么既需要 IP 又需要 MAC？
- 访问远端服务器时，ARP 解析谁？
- 路由器转发会改变哪些字段？
- ping 通为什么不代表服务正常？
- 默认路由与最长前缀匹配怎么配合？
- NAT 如何让多台设备共享外侧地址？
- 为什么小包能通、大包可能失败？
- IPv6 与 IPv4 在分片、邻居发现和广播上有什么区别？

## 23.4 核心公式

| 场景 | 公式／规则 |
|---|---|
| IPv4 网络地址 | IP 按位与掩码 |
| 主机位数 | 32 - 前缀长度 |
| 地址总数 | 2^(主机位数) |
| 常规可分配地址数 | 2^(主机位数) - 2，注意 /31、/32 例外 |
| 等长拆分后的子网数 | 2^(新增前缀位数) |
| IPv4 首部字节数 | IHL × 4 |
| IP 负载长度 | IP 总长度 - IP 首部长度 |
| 非最后分片最大负载 | floor((MTU - 分片首部长度)/8) × 8 |
| 片偏移字段 | 该分片起始负载位置 / 8 |
| 普通路由查找 | 最长前缀匹配 |
| 传输时延 | 分组比特数 / 链路比特速率 |

## 23.6 不容易混淆的一组总结

```text
DNS：域名对应什么记录？
路由：到目的网络从哪里走？
ARP／NDP：当前链路上下一跳是谁、如何交付？
IP：把分组送向目标主机。
TCP／UDP：把数据交给相应应用端点。
ICMP：报告网络层问题并支持诊断。
NAT／NAPT：转换经过设备的地址／端口等。
```
