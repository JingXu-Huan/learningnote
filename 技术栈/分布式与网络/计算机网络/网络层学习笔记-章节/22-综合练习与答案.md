## 题 1：地址块计算

主机地址是 `172.16.35.7/20`，求掩码、网络地址、广播地址和常规可分配地址数量。

**答案：**

```text
掩码：255.255.240.0
网络地址：172.16.32.0
广播地址：172.16.47.255
主机位：12
常规可分配数量：2^12 - 2 = 4094
```

## 题 2：容量规划

一个部门需要 120 个终端地址和 1 个网关地址，选择最小的常规 IPv4 子网。

**答案：**至少需要 121 个可分配地址。`/26` 只有 62 个，不够；`/25` 有 126 个，满足需求。

## 题 3：同网段判断

两台主机分别是 `192.168.8.70/27` 和 `192.168.8.95/27`。第二个地址能作为普通主机地址吗？

**答案：**

```text
/27 每块 32 个地址
70 落在 64～95
网络地址：192.168.8.64
广播地址：192.168.8.95
可分配范围：192.168.8.65～192.168.8.94
```

第二个地址是该块广播地址，不能作为这个常规子网的普通主机地址。

## 题 4：最长前缀匹配

路由表如下：

| 目的前缀 | 下一跳 |
|---|---|
| 0.0.0.0/0 | A |
| 172.16.0.0/12 | B |
| 172.16.32.0/20 | C |
| 172.16.40.0/24 | D |

目的 IP 是 `172.16.40.9`，选择谁？若目的 IP 是 `172.16.41.9` 呢？

**答案：**前者选 D；后者不匹配 `/24`，但匹配 `/20`，选 C。

## 题 5：路由聚合

将 `10.0.8.0/24`、`10.0.9.0/24`、`10.0.10.0/24`、`10.0.11.0/24` 精确聚合。

**答案：**`10.0.8.0/22`。第三字节 8 是大小为 4 的块的对齐起点，范围为 8～11。

## 题 6：IP 分片

IPv4 数据报总长度 3000 字节，首部 20 字节，无选项。MTU=1000，允许分片。求各分片总长度、片偏移和 MF。

**答案：**

```text
原负载：3000 - 20 = 2980
普通分片最大负载：floor((1000 - 20)/8) × 8 = 976
```

| 分片 | 负载长度 | 总长度 | 片偏移 | MF |
|---|---:|---:|---:|---:|
| 1 | 976 | 996 | 0 | 1 |
| 2 | 976 | 996 | 122 | 1 |
| 3 | 976 | 996 | 244 | 1 |
| 4 | 52 | 72 | 366 | 0 |

**易错点：**不能把前三片负载取为 980，它不是 8 的整数倍。

## 题 7：跨网段交付

主机 `192.168.1.10/24` 经网关 `192.168.1.1` 访问 `203.0.113.20`。第一跳以太网帧的目的 MAC 和 IP 数据报的目的 IP 分别是什么？

**答案：**目的 MAC 是网关 LAN 接口 MAC；目的 IP 是 `203.0.113.20`。

## 题 8：TTL

一个普通 IPv4 分组初始 TTL=3，途中每台路由器减 1，需要经过 4 台路由器才能到达目标。会在哪里被丢弃？

**答案：**第三台路由器。它把 TTL 从 1 减到 0，不能继续转发。可能生成 ICMP Time Exceeded。

## 题 9：距离向量更新

路由器 A 从 B、C 得到到目标 N 的距离：B 通告 5，C 通告 2。A 到 B 开销 1，到 C 开销 3。选哪个下一跳？

**答案：**经 B 的开销是 6，经 C 的开销是 5，选择 C。

## 题 10：协议识别

以下说法哪些错误？

1. OSPF 使用 TCP 89 端口。
2. ICMPv4 封装在 IPv4 中。
3. ARP 查询通常跨越互联网寻找远端服务器 MAC。
4. BGP 使用 TCP 会话交换路由信息。
5. IPv6 路由器可以像 IPv4 路由器一样为过大的分组分片。

**答案：**1、3、5 错误。OSPF 使用 IP 协议号 89；ARP 通常仅在本地链路解析；IPv6 路由器不进行这种沿途分片。
