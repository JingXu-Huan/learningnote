## 3.1 IP 地址是什么

IP 地址是网络层的逻辑地址，严格来说通常分配给**网络接口**。

一台电脑可以有有线网卡、无线网卡、回环接口和虚拟网卡，因此可以同时拥有多个 IP 地址。一个接口也可以配置多个 IP。

路由器连接多个网络，通常在不同接口上拥有不同的 IP 地址。

## 3.2 MAC 地址是什么

MAC 地址用于以太网等链路上的帧交付。常见以太网 MAC 地址长 48 位。

在一个以太网链路上，发送方需要知道当前下一跳的 MAC，才能构造目的 MAC 正确的帧。

MAC 不是不可修改的永久身份证。它可以被配置、虚拟化或随机化。

## 3.3 为什么两种地址都需要

- IP 地址具有网络前缀，便于按网络进行路由和聚合。
- MAC 地址解决当前链路的帧交付问题。
- IP 可以运行在不同链路技术之上，不必把所有网络都统一成以太网。

| 地址 | 所在层 | 在一次转发中的作用 |
|---|---|---|
| 目的 IP | 网络层 | 指向最终目的接口，用于路由查找 |
| 目的 MAC | 链路层 | 指向当前以太网链路上的下一跳 |

## 3.4 跨越路由器时哪些字段变化

在**普通 IPv4 路由转发，不考虑 NAT 与隧道**的场景中：

| 内容 | 通常是否改变 |
|---|---|
| 源 IP | 不改变 |
| 目的 IP | 不改变 |
| TTL | 每次路由转发至少减 1 |
| IPv4 首部校验和 | 随首部变化而更新 |
| 以太网源 MAC、目的 MAC | 旧帧被解封装，在出口链路重新封装 |

如果出口也是以太网，新帧的源 MAC 通常属于路由器出口接口，目的 MAC 属于下一跳。

**MAC 在路由跳之间重新选择；普通二层交换机转发帧时，不会因为经过一个交换机就替换源、目的 MAC。**
