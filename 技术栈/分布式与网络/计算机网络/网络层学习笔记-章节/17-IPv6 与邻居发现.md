## 17.1 IPv6 的主要变化

IPv6 地址长 128 位，最明显的价值是扩大地址空间。[2]

常见写法：

```text
2001:0db8:0000:0000:0000:0000:0000:0001
可简写为：2001:db8::1
```

规则：

- 每组的前导 0 可以省略。
- 一段连续的全 0 组可以用 `::` 压缩。
- 同一个地址中 `::` 最多出现一次，以免恢复时产生歧义。

`2001:db8::/32` 用于文档示例。

## 17.2 IPv4 与 IPv6 对比

| 对比项 | IPv4 | IPv6 |
|---|---|---|
| 地址长度 | 32 位 | 128 位 |
| 基础首部 | 20～60 字节 | 固定 40 字节 |
| 首部校验和 | 有 | 无 |
| 生命周期字段 | TTL | Hop Limit |
| 沿途路由器分片 | 允许分片时可以 | 不允许 |
| 广播 | 有 | 没有，相关功能多由组播承担 |
| 邻居地址解析 | ARP | NDP |
| 上层协议指示 | Protocol | Next Header，可指向扩展首部或上层协议 |

IPv6 基础首部固定 40 字节，不代表带扩展首部的整个首部链永远只有 40 字节。

## 17.3 IPv6 常见地址

| 地址／范围 | 用途 |
|---|---|
| :: | 未指定地址 |
| ::1 | 回环地址 |
| fe80::/10 | 链路本地地址范围 |
| fc00::/7 | 唯一本地地址 ULA 范围，常见本地生成地址使用 fd00::/8 |
| ff00::/8 | 组播地址 |
| 2001:db8::/32 | 文档示例地址 |

普通 IPv6 局域网常用 `/64`，SLAAC 等机制与这个结构有关，但不是所有 IPv6 路由前缀都必须是 `/64`。

## 17.4 NDP 是什么

NDP，即邻居发现协议，基于 ICMPv6。[8]

它承担多项功能：

- 地址解析。
- 邻居可达性检测。
- 路由器发现。
- 前缀发现。
- 配合重复地址检测等机制。

常见报文包括 Neighbor Solicitation、Neighbor Advertisement、Router Solicitation 和 Router Advertisement。

IPv6 地址解析通常利用特定组播，不能直接称为“IPv6 版 ARP 广播”。

## 17.5 IPv6 自动配置

- SLAAC：主机利用路由器通告等信息生成和配置地址。
- DHCPv6：通过 DHCPv6 服务获得地址或其他配置信息。

IPv6 的默认路由通常通过路由器通告学习，不应机械套用 IPv4 DHCP 的所有流程。

## 17.6 IPv6 并不自动保证安全

更大的地址空间不意味着网络默认可信，也不意味着所有 IPv6 流量都会自动加密。

是否允许入站仍取决于路由、防火墙和服务配置等。
