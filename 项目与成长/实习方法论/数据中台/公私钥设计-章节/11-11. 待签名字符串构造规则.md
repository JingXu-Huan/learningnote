# 11. 待签名字符串构造规则

签名规则必须严格统一，否则客户端和服务端会算出不同结果。

推荐规则：

```text
1. HTTP Method 转大写，例如 POST、GET
2. Request Path 不包含域名，例如 /api/order/create
3. Query 参数按 key 字典序排序
4. AppId 原样参与签名
5. KeyId 原样参与签名
6. Timestamp 原样参与签名
7. Nonce 原样参与签名
8. BodySha256 原样参与签名
9. 每一段使用 \n 分隔
```

Java 示例：

```java
public static String buildSignContent(
        String method,
        String path,
        String query,
        String appId,
        String keyId,
        String timestamp,
        String nonce,
        String bodySha256
) {
    return method.toUpperCase() + "\n"
            + path + "\n"
            + query + "\n"
            + appId + "\n"
            + keyId + "\n"
            + timestamp + "\n"
            + nonce + "\n"
            + bodySha256;
}
```
