# 16. 错误码设计

推荐统一返回结构：

```json
{
  "code": 401001,
  "message": "Missing authentication headers"
}
```

常见错误码：

| 错误码 | 含义 |
|---|---|
| `401001` | 缺少认证请求头 |
| `401002` | AppId 不存在 |
| `401003` | AppId 已禁用 |
| `401004` | KeyId 不存在 |
| `401005` | KeyId 已禁用 |
| `401006` | 密钥已过期 |
| `401007` | 请求已过期 |
| `401008` | Nonce 重复 |
| `401009` | 请求体摘要不一致 |
| `401010` | 签名错误 |
| `403001` | 没有接口权限 |
| `429001` | 调用频率超限 |
