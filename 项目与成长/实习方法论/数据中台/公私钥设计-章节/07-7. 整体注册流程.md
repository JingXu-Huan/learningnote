# 7. 整体注册流程

## 7.1 调用方生成 RSA 密钥对

调用方在自己的环境中生成：

```text
privateKey
publicKey
```

调用方自己保存 `privateKey`，并把 `publicKey` 提交给你的 API 平台。

---

## 7.2 服务端保存公钥

服务端为调用方创建应用：

```text
AppId = app_001
```

然后保存调用方提交的公钥：

```text
app_001 + key_202607 -> publicKey
```

---

## 7.3 服务端返回 AppId 和 KeyId

服务端可以把下面两个值返回给调用方：

```text
AppId = app_001
KeyId = key_202607
```

调用方后续请求 API 时，需要带上这两个字段。
