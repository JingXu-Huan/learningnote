# 2. 核心原则

## 2.1 服务端不要保存用户私钥

在 RSA 非对称签名方案中：

```text
客户端保存 privateKey
服务端保存 publicKey
```

客户端用私钥签名，服务端用公钥验签。

服务端不应该接触用户私钥，否则非对称签名的意义就没了。

---

## 2.2 服务端不是根据私钥找公钥

服务端收到请求后，不能也不应该根据用户私钥找公钥。

正确方式是：

```text
根据 AppId + KeyId 找到 publicKey
```

也就是说，服务端保存的是类似下面的映射关系：

```text
app_001 + key_202607 -> publicKey_A
app_001 + key_202608 -> publicKey_B
```

请求进来时，调用方必须告诉服务端自己用的是哪一把密钥。
