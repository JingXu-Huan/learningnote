# 8. 客户端签名流程

假设调用方请求接口：

```http
POST /api/order/create?channel=web
```

请求体：

```json
{
  "orderNo": "202607080001",
  "amount": 100
}
```

客户端需要执行以下步骤。

---

## 8.1 生成 timestamp 和 nonce

```text
timestamp = 1752033600000
nonce = abc123
```

---

## 8.2 计算请求体摘要

对请求体原文计算 SHA-256：

```text
bodyHash = SHA256(body)
```

示例：

```text
X-Body-Sha256: 2cf24dba5fb0a30e26e83b2ac5b9e29e...
```

---

## 8.3 构造待签名字符串

推荐将以下内容纳入签名：

```text
HTTP Method
Request Path
Query String
AppId
KeyId
Timestamp
Nonce
BodySha256
```

示例：

```text
POST
/api/order/create
channel=web
app_001
key_202607
1752033600000
abc123
2cf24dba5fb0a30e26e83b2ac5b9e29e...
```

注意：`AppId` 和 `KeyId` 也要参与签名，防止请求头被替换。

---

## 8.4 使用私钥签名

调用方使用自己的 privateKey 对待签名字符串签名：

```text
signature = RSA_SIGN(privateKey, signContent)
```

签名算法推荐：

```text
SHA256withRSA
```

最终请求头：

```http
X-App-Id: app_001
X-Key-Id: key_202607
X-Timestamp: 1752033600000
X-Nonce: abc123
X-Body-Sha256: 2cf24dba5fb0a30e26e83b2ac5b9e29e...
X-Signature: xxxxx
```
