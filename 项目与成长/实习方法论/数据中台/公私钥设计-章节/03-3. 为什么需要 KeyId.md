# 3. 为什么需要 KeyId

如果一个用户只有一个 AppId，但是这个 AppId 下面有多把 publicKey，例如：

```text
app_001 -> publicKey_A
app_001 -> publicKey_B
app_001 -> publicKey_C
```

如果请求里只带：

```http
X-App-Id: app_001
X-Signature: xxxxx
```

服务端并不知道应该用哪一把 publicKey 验签，只能轮询：

```text
用 publicKey_A 验签
失败，再用 publicKey_B 验签
失败，再用 publicKey_C 验签
成功，放行
```

这种方案可以实现，但不推荐。
