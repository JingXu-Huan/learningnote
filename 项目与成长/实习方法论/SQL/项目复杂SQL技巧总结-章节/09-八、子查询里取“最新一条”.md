# 八、子查询里取“最新一条”

## 8.1 场景

订单有多条日志，但主表只想挂住“最近一次处理结果”。

## 8.2 演示表

```sql
order_detail(id, latest_log_id)
order_log(id, order_id, result, create_time)
```

## 8.3 示例 SQL

```sql
SELECT od.id,
       (
           SELECT ol.result
           FROM order_log ol
           WHERE ol.order_id = od.id
           ORDER BY ol.create_time DESC, ol.id DESC
           LIMIT 1
       ) AS latest_result
FROM order_detail od;
```

## 8.4 学习重点

- 相关子查询常用来拿“每个主记录的最新一条子记录”。
- 如果量很大，要考虑索引和改写方式。
