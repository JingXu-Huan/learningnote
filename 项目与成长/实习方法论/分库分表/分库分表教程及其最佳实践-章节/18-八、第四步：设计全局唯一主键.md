# 八、第四步：设计全局唯一主键

分库之后，不能继续依赖单个 MySQL 实例的自增主键生成全局唯一 ID。

常见方案包括：

* UUID；
* 数据库号段；
* Redis 自增；
* Snowflake；
* Leaf 等号段服务；
* 自研 ID 服务。

ShardingSphere 内置了主键生成算法，官方示例支持通过 `keyGenerateStrategies` 配置逻辑表、主键列和生成器，并可使用 `SNOWFLAKE` 生成器。

使用 Snowflake 时需要注意：

* 机器标识不能冲突；
* 系统时间不能随意回拨；
* ID 虽然整体趋势递增，但不等于严格连续；
* 不要让业务依赖 ID 连续性；
* ID 字段通常使用 `BIGINT`。
