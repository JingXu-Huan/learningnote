# 5. 逻辑表和真实表

在分片系统中，业务代码使用的表称为**逻辑表**。

例如：

```sql
SELECT *
FROM t_order
WHERE user_id = 1001
  AND order_id = 90001;
```

这里的 `t_order` 是逻辑表。

数据库中真正存在的可能是：

```text
ds_0.t_order_0
ds_0.t_order_1
ds_0.t_order_2
ds_0.t_order_3

ds_1.t_order_0
ds_1.t_order_1
ds_1.t_order_2
ds_1.t_order_3
```

这些表称为真实表或物理表。
