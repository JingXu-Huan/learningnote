# 十二、没有分片键会发生什么

执行以下 SQL：

```sql
SELECT *
FROM t_order
WHERE order_status = 'PAID';
```

SQL 中既没有 `user_id`，也没有 `order_id`。

ShardingSphere 无法计算目标数据库和目标表，只能访问所有可能的数据节点：

```text
ds_0.t_order_0
ds_0.t_order_1
ds_0.t_order_2
ds_0.t_order_3
ds_1.t_order_0
ds_1.t_order_1
ds_1.t_order_2
ds_1.t_order_3
```

然后将结果归并。

这种操作称为：

* 全路由；
* 广播路由；
* 全分片扫描。

全路由不一定完全禁止，但必须控制：

* 执行频率；
* 返回数据量；
* 分片数量；
* 排序和聚合复杂度；
* 是否位于核心在线链路。

对于“扫描所有待支付订单并关闭超时订单”一类任务，可以考虑：

* 按照分片并行执行；
* 维护独立的延迟任务；
* 写入消息队列或延迟队列；
* 建立任务索引表；
* 使用调度系统逐个处理分片。
