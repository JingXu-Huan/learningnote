# 十三、不要对分片键进行函数计算

假设 `create_time` 是分片键，以下写法可能导致无法提取分片值：

```sql
SELECT *
FROM t_order
WHERE DATE(create_time) = '2026-07-17';
```

更好的写法是：

```sql
SELECT *
FROM t_order
WHERE create_time >= '2026-07-17 00:00:00'
  AND create_time <  '2026-07-18 00:00:00';
```

官方限制说明指出，当分片键被放入函数或运算表达式时，路由引擎可能无法提取其值，从而产生全路由。
