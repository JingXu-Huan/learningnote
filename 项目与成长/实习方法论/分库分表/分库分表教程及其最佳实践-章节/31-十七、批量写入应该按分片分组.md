# 十七、批量写入应该按分片分组

假设一次批量写入 1000 个订单：

```java
orderMapper.batchInsert(orders);
```

如果这些订单分布在不同数据库和表中，中间件必须拆分 SQL，并发送到多个数据节点。

更可控的方式是先按照目标分片进行分组：

```java
Map<ShardKey, List<Order>> groupedOrders =
        orders.stream()
                .collect(Collectors.groupingBy(order -> {
                    int databaseIndex = Math.floorMod(order.getUserId(), 2);
                    int tableIndex = Math.floorMod(order.getOrderId(), 4);
                    return new ShardKey(databaseIndex, tableIndex);
                }));
```

然后按照分组分别批量写入。

这样可以：

* 降低单次 SQL 路由复杂度；
* 控制每批大小；
* 减少跨节点事务；
* 更容易进行失败重试；
* 提高批量执行效率。

但业务代码中的分片算法必须与中间件配置保持一致。更加稳妥的做法是将批处理分组逻辑封装在统一的数据访问组件中，避免算法散落在业务代码里。
