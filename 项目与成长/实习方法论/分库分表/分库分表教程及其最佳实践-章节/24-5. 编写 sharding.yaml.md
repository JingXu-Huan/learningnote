# 5. 编写 sharding.yaml

在 `src/main/resources` 下创建 `sharding.yaml`：

```yaml
databaseName: order_db

dataSources:
  ds_0:
    dataSourceClassName: com.zaxxer.hikari.HikariDataSource
    driverClassName: com.mysql.cj.jdbc.Driver
    jdbcUrl: jdbc:mysql://127.0.0.1:3306/demo_order_0?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=UTF-8
    username: root
    password: root

  ds_1:
    dataSourceClassName: com.zaxxer.hikari.HikariDataSource
    driverClassName: com.mysql.cj.jdbc.Driver
    jdbcUrl: jdbc:mysql://127.0.0.1:3306/demo_order_1?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=UTF-8
    username: root
    password: root

rules:
  - !SHARDING
    tables:
      t_order:
        actualDataNodes: ds_${0..1}.t_order_${0..3}
        databaseStrategy:
          standard:
            shardingColumn: user_id
            shardingAlgorithmName: order_database_inline
        tableStrategy:
          standard:
            shardingColumn: order_id
            shardingAlgorithmName: order_table_inline

      t_order_item:
        actualDataNodes: ds_${0..1}.t_order_item_${0..3}
        databaseStrategy:
          standard:
            shardingColumn: user_id
            shardingAlgorithmName: order_database_inline
        tableStrategy:
          standard:
            shardingColumn: order_id
            shardingAlgorithmName: order_item_table_inline

    bindingTables:
      - t_order,t_order_item

    keyGenerateStrategies:
      order_id_strategy:
        keyGenerateType: column
        keyGeneratorName: snowflake
        logicTable: t_order
        keyGenerateColumn: order_id

      order_item_id_strategy:
        keyGenerateType: column
        keyGeneratorName: snowflake
        logicTable: t_order_item
        keyGenerateColumn: item_id

    shardingAlgorithms:
      order_database_inline:
        type: INLINE
        props:
          algorithm-expression: ds_${user_id % 2}

      order_table_inline:
        type: INLINE
        props:
          algorithm-expression: t_order_${order_id % 4}

      order_item_table_inline:
        type: INLINE
        props:
          algorithm-expression: t_order_item_${order_id % 4}

    keyGenerators:
      snowflake:
        type: SNOWFLAKE

  - !BROADCAST
    tables:
      - t_region

props:
  sql-show: true
```

官方 YAML 规则中，`actualDataNodes` 用于定义真实节点，`databaseStrategy` 和 `tableStrategy` 分别定义分库与分表策略，`shardingAlgorithms` 声明算法，`keyGenerateStrategies` 和 `keyGenerators` 负责主键生成。

`sql-show: true` 会输出真实路由 SQL，适合开发和测试环境。生产环境中通常应关闭，避免：

* 输出大量日志；
* 暴露 SQL 参数；
* 增加日志存储压力；
* 影响问题排查效率。
