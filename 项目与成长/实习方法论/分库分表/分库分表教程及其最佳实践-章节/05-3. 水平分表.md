# 3. 水平分表

水平分表是把一张逻辑表中的不同行，拆分到多张结构相同的物理表。

例如：

```text
逻辑表：t_order

物理表：
t_order_0
t_order_1
t_order_2
t_order_3
```

根据订单编号进行取模：

```text
order_id % 4
```

那么：

```text
order_id = 10001 → t_order_1
order_id = 10002 → t_order_2
order_id = 10003 → t_order_3
order_id = 10004 → t_order_0
```

应用程序操作的是逻辑表 `t_order`，分片中间件负责将 SQL 路由到真实表。
