# 1. 分片结构

数据库：

```text
demo_order_0
demo_order_1
```

每个数据库包含：

```text
t_order_0
t_order_1
t_order_2
t_order_3

t_order_item_0
t_order_item_1
t_order_item_2
t_order_item_3

t_region
```

分片规则：

```text
按照 user_id % 2 分库
按照 order_id % 4 分表
```

查询特点：

| 查询条件                 | 路由范围           |
| -------------------- | -------------- |
| `user_id + order_id` | 1 个数据库、1 张表    |
| 只有 `user_id`         | 1 个数据库、4 张表    |
| 只有 `order_id`        | 2 个数据库、每库 1 张表 |
| 两个分片键都没有             | 2 个数据库、共 8 张表  |

因此，订单详情接口最好同时传入：

```text
user_id
order_id
```

不要只根据 `order_id` 查询。
