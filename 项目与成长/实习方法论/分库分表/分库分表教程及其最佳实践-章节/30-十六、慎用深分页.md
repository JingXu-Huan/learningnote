# 十六、慎用深分页

下面的查询在分片环境中成本很高：

```sql
SELECT *
FROM t_order
WHERE user_id = #{userId}
ORDER BY create_time DESC
LIMIT 100000, 20;
```

每个相关分片可能需要读取大量数据，ShardingSphere 再进行归并和截取。

推荐使用游标式分页：

```sql
SELECT *
FROM t_order
WHERE user_id = #{userId}
  AND (
      create_time < #{lastCreateTime}
      OR (
          create_time = #{lastCreateTime}
          AND order_id < #{lastOrderId}
      )
  )
ORDER BY create_time DESC, order_id DESC
LIMIT 20;
```

这种方式也称为：

* Seek Pagination；
* Keyset Pagination；
* 游标分页。

它通常比大偏移量分页更适合高并发订单列表。
