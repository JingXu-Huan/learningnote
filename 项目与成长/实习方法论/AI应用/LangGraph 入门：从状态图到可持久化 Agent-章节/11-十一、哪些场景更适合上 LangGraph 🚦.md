# 十一、哪些场景更适合上 LangGraph 🚦

不是所有 LLM 应用都需要 LangGraph。

下面这些场景更值得考虑：

## 1. 流程有明显多步决策

比如：

- 先分类，再检索，再生成，再复核

## 2. 需要可恢复执行

比如：

- 长任务不能因为一次错误就全部重来

## 3. 需要 human-in-the-loop

比如：

- 关键节点要人工确认

## 4. 需要持久化状态

比如：

- 多轮对话要续接
- 跨步骤要留状态

## 5. 多 Agent 或子图协作

这类场景 LangGraph 会比手搓流程更稳。

反过来，如果你只是：

- 调一次模型
- 调一个工具
- 回一个结果

那先用 LangChain 就够了。
