# WebSocket 快速入门 😎😎😎

## 一、Spring Boot 整合 WebSocket

Spring Boot 内置了 WebSocket 支持，无需额外引入依赖（Spring-boot-starter-websocket 已在 web 包中）。

### 1.1 引入依赖

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-websocket</artifactId>
</dependency>
```

### 1.2 启用 WebSocket

```java
@Configuration
@EnableWebSocket
public class WebSocketConfig implements WebSocketConfigurer {

    @Override
    public void registerWebSocketHandlers(WebSocketHandlerRegistry registry) {
        registry.addHandler(myHandler(), "/ws")
                .setAllowedOrigins("*");  // 生产环境建议限制具体域名
    }

    @Bean
    public WebSocketHandler myHandler() {
        return new MyWebSocketHandler();
    }
}
```

### 1.3 实现 TextWebSocketHandler

Spring 提供了 `TextWebSocketHandler`（处理文本帧）和 `BinaryWebSocketHandler`（处理二进制帧）。

```java
public class MyWebSocketHandler extends TextWebSocketHandler {

    // 存储所有在线会话
    private final CopyOnWriteMap<String, WebSocketSession> sessions = new CopyOnWriteMap<>();

    // ==================== 生命周期 ====================

    @Override
    public void afterConnectionEstablished(WebSocketSession session) throws Exception {
        // 客户端连接建立时调用
        sessions.put(session.getId(), session);
        System.out.println("连接建立：" + session.getId());
    }

    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) throws Exception {
        // 收到文本消息时调用
        String payload = message.getPayload();
        System.out.println("收到消息 from " + session.getId() + ": " + payload);

        // 回复消息
        session.sendMessage(new TextMessage("服务器收到: " + payload));
    }

    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) throws Exception {
        // 连接关闭时调用
        sessions.remove(session.getId());
        System.out.println("连接关闭：" + session.getId());
    }

    @Override
    public void handleTransportError(WebSocketSession session, Throwable exception) throws Exception {
        // 传输异常时调用
        sessions.remove(session.getId());
        exception.printStackTrace();
    }

    // ==================== 广播消息 ====================

    // 广播给所有客户端
    public void broadcast(String message) {
        TextMessage textMessage = new TextMessage(message);
        sessions.values().forEach(session -> {
            try {
                if (session.isOpen()) {
                    session.sendMessage(textMessage);
                }
            } catch (IOException e) {
                e.printStackTrace();
            }
        });
    }

    // 发送给指定客户端
    public void sendToUser(String sessionId, String message) throws IOException {
        WebSocketSession session = sessions.get(sessionId);
        if (session != null && session.isOpen()) {
            session.sendMessage(new TextMessage(message));
        }
    }
}
```

### 1.4 使用 @Scheduled 实现心跳

```java
@Configuration
public class HeartbeatConfig {

    @Autowired
    private MyWebSocketHandler webSocketHandler;

    @Scheduled(fixedRate = 30000)  // 每 30 秒心跳一次
    public void heartbeat() {
        webSocketHandler.broadcast("heartbeat:" + System.currentTimeMillis());
    }
}
```

## 二、前端 WebSocket 客户端

### 2.1 基础使用

```javascript
// 建立连接
const ws = new WebSocket("ws://localhost:8080/ws");

ws.onopen = function() {
    console.log("连接已建立");
    ws.send("Hello Server!");
};

ws.onmessage = function(event) {
    console.log("收到消息:", event.data);
};

ws.onerror = function(error) {
    console.error("WebSocket 错误:", error);
};

ws.onclose = function(event) {
    console.log("连接关闭, code:", event.code, "reason:", event.reason);
};

// 主动关闭连接
ws.close(1000, "正常关闭");
```

### 2.2 重连机制（实际项目必备）

```javascript
class WebSocketClient {
    constructor(url) {
        this.url = url;
        this.ws = null;
        this.reconnectInterval = 3000;
        this.maxReconnectAttempts = 10;
        this.reconnectCount = 0;
    }

    connect() {
        this.ws = new WebSocket(this.url);

        this.ws.onopen = () => {
            console.log("连接成功");
            this.reconnectCount = 0;
        };

        this.ws.onmessage = (event) => {
            console.log("收到:", event.data);
        };

        this.ws.onclose = (event) => {
            console.log("连接断开:", event.code, event.reason);
            this.scheduleReconnect();
        };

        this.ws.onerror = (error) => {
            console.error("错误:", error);
        };
    }

    scheduleReconnect() {
        if (this.reconnectCount < this.maxReconnectAttempts) {
            this.reconnectCount++;
            console.log(`${this.reconnectInterval}ms 后尝试第 ${this.reconnectCount} 次重连...`);
            setTimeout(() => this.connect(), this.reconnectInterval);
        } else {
            console.error("达到最大重连次数，放弃");
        }
    }

    send(message) {
        if (this.ws && this.ws.readyState === WebSocket.OPEN) {
            this.ws.send(message);
        } else {
            console.error("连接未建立，无法发送");
        }
    }
}
```

### 2.3 WebSocket 状态

| 状态 | 值 | 含义 |
|------|---|------|
| CONNECTING | 0 | 连接正在建立 |
| OPEN | 1 | 连接已打开，可发送/接收 |
| CLOSING | 2 | 连接正在关闭 |
| CLOSED | 3 | 连接已关闭 |

## 三、完整示例：群聊功能

### 3.1 服务端：管理用户会话

```java
@Component
public class ChatWebSocketHandler extends TextWebSocketHandler {

    // sessionId -> session
    private final Map<String, WebSocketSession> sessions = new ConcurrentHashMap<>();

    // sessionId -> username
    private final Map<String, String> userNames = new ConcurrentHashMap<>();

    @Override
    public void afterConnectionEstablished(WebSocketSession session) throws Exception {
        sessions.put(session.getId(), session);
        // 从 query 参数获取用户名
        String userName = session.getUri().getQuery().split("=")[1];
        userNames.put(session.getId(), userName);
        broadcast(userName + " 加入了群聊");
    }

    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) throws Exception {
        String userName = userNames.get(session.getId());
        String content = message.getPayload();
        broadcast("[" + userName + "]: " + content);
    }

    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) throws Exception {
        String userName = userNames.remove(session.getId());
        sessions.remove(session.getId());
        if (userName != null) {
            broadcast(userName + " 离开了群聊");
        }
    }

    private void broadcast(String message) {
        TextMessage textMessage = new TextMessage(message);
        sessions.values().forEach(s -> {
            try {
                if (s.isOpen()) s.sendMessage(textMessage);
            } catch (IOException e) {
                e.printStackTrace();
            }
        });
    }
}
```

### 3.2 前端：简单聊天界面

```html
<!DOCTYPE html>
<html>
<head>
    <title>WebSocket 群聊</title>
</head>
<body>
    <div id="chat"></div>
    <input id="msg" placeholder="输入消息">
    <button onclick="send()">发送</button>

    <script>
        const username = new URLSearchParams(window.location.search).get("username") || "游客";
        const ws = new WebSocket(`ws://localhost:8080/ws?username=${username}`);

        ws.onmessage = function(event) {
            const div = document.createElement("div");
            div.textContent = event.data;
            document.getElementById("chat").appendChild(div);
        };

        function send() {
            const msg = document.getElementById("msg").value;
            ws.send(msg);
            document.getElementById("msg").value = "";
        }
    </script>
</body>
</html>
```

访问：`http://localhost:8080/chat.html?username=Alice`

## 四、STOMP 协议（更高级的用法）

如果觉得原生 WebSocket 消息不够方便，可以引入 **STOMP**（Simple Text Oriented Messaging Protocol），它为 WebSocket 提供了一个子协议，让消息传递更像"消息队列"：

### 4.1 配置 STOMP

```java
@Configuration
@EnableWebSocketMessageBroker
public class StompConfig implements WebSocketMessageBrokerConfigurer {

    @Override
    public void configureMessageBroker(MessageBrokerRegistry registry) {
        registry.enableSimpleBroker("/topic", "/queue");  // 消息代理前缀
        registry.setApplicationDestinationPrefixes("/app");  // 应用目标前缀
    }

    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        registry.addEndpoint("/ws").withSockJS();  // 支持 SockJS 回退
    }
}
```

### 4.2 消息发送与订阅

```javascript
const stompClient = Stomp.over(new WebSocket("/ws"));

stompClient.connect({}, function(frame) {
    // 订阅主题
    stompClient.subscribe("/topic/notice", function(message) {
        console.log("收到通知:", message.body);
    });
});

// 发送消息到服务端
stompClient.send("/app/chat", {}, JSON.stringify({
    username: "Alice",
    content: "你好"
}));
```

### 4.3 什么时候用 STOMP

- 需要**消息订阅机制**（发布-订阅模型）
- 需要**多协议兼容**（SockJS 回退支持）
- 已有**RabbitMQ / ActiveMQ** 等消息中间件集成
- 简单的一对一消息推送，原生 WebSocket 就够了

## 五、常见问题与最佳实践

### 1. 跨域问题

WebSocket 也受同源策略限制，后端需要配置 `setAllowedOrigins("*")` 或指定具体域名。

### 2. 消息安全

- 生产环境建议使用 **WSS（WebSocket Secure）**，即 TLS/SSL 加密
- 可以在握手阶段验证 Token，防止恶意连接

### 3. 集群环境下的广播

单机广播没问题，但多节点部署时，A 节点发的消息不会推到 B 节点的客户端。需要：
- 消息中间件（RabbitMQ / RocketMQ）转发
- Redis Pub/Sub 同步
- 使用专门的 WebSocket 网关（如 Spring Cloud Gateway）

### 4. 连接数限制

单个浏览器对同一域名的 WebSocket 连接数**没有明确限制**，但实际受限于系统资源。建议一个标签页只维持一个 WebSocket 连接。

### 5. 心跳保活

务必实现心跳机制，防止中间链路断开后连接变成死连接。推荐：
- 协议层：定期 Ping/Pong
- 应用层：定时发送心跳消息

## 六、一句话总结

> Spring Boot 通过 `WebSocketConfigurer` + `TextWebSocketHandler` 可以快速实现 WebSocket 服务；前端用原生 `WebSocket` API 连接，复杂场景可引入 STOMP 协议；实际项目中需要关注跨域、重连、心跳、集群广播等问题。
