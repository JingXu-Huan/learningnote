# 11. 模式（Schema）

PostgreSQL 的 `schema` 是数据库内的逻辑命名空间，MySQL 中 `schema` 等同于 `database`。

```sql
-- 创建模式
CREATE SCHEMA app;

-- 在模式下建表
CREATE TABLE app.users (
    id SERIAL PRIMARY KEY,
    name TEXT NOT NULL
);

-- 设置搜索路径（默认 public）
SET search_path TO app, public;

-- 查看所有模式
SELECT schema_name FROM information_schema.schemata;
```

| 默认模式 | 说明 |
|----------|------|
| `public` | 默认模式，所有用户可访问 |
| `pg_catalog` | 系统表 |
| `information_schema` | SQL 标准信息视图 |
