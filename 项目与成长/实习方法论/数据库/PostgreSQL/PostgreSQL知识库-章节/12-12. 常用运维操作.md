# 12. 常用运维操作

## 用户与权限

```sql
-- 创建用户
CREATE USER appuser WITH PASSWORD 'secret123';

-- 授权
GRANT SELECT, INSERT, UPDATE ON ALL TABLES IN SCHEMA public TO appuser;
GRANT USAGE ON ALL SEQUENCES IN SCHEMA public TO appuser;

-- 授予只读权限
GRANT SELECT ON ALL TABLES IN SCHEMA public TO readonly_user;

-- 回收权限
REVOKE ALL ON ALL TABLES IN SCHEMA public FROM appuser;
```

## 表维护

```sql
-- 查看表大小
SELECT pg_size_pretty(pg_total_relation_size('users')) AS total_size;

-- 查看数据库大小
SELECT pg_size_pretty(pg_database_size('testdb')) AS db_size;

-- 手动 VACUUM（清理死元组）
VACUUM ANALYZE users;

-- 查看活跃连接
SELECT pid, usename, application_name, state, query
FROM pg_stat_activity
WHERE datname = 'testdb';

-- 终止连接
SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE usename = 'appuser';

-- 查看慢查询
SELECT pid, now() - pg_stat_activity.query_start AS duration, query
FROM pg_stat_activity
WHERE state = 'active' AND now() - query_start > interval '5 seconds';

-- 查看索引使用情况
SELECT schemaname, relname, indexrelname, idx_scan, idx_tup_read
FROM pg_stat_user_indexes
ORDER BY idx_scan DESC;
```

## 备份与恢复

```powershell
# 备份（在宿主机执行）
docker exec postgres pg_dump -U postgres testdb > backup.sql

# 恢复
docker exec -i postgres psql -U postgres testdb < backup.sql

# 自定义格式备份（支持并行恢复）
docker exec postgres pg_dump -U postgres -Fc testdb > backup.dump

# 恢复自定义格式
docker exec -i postgres pg_restore -U postgres -d testdb < backup.dump
```
