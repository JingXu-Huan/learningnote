# 10. 事务与锁

## 事务

```sql
BEGIN;                              -- 开始事务
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;                             -- 提交
-- ROLLBACK;                        -- 回滚
```

## SAVEPOINT

```sql
BEGIN;
INSERT INTO orders (user_id, amount) VALUES (1, 100);
SAVEPOINT sp1;
INSERT INTO orders (user_id, amount) VALUES (2, 200);
ROLLBACK TO SAVEPOINT sp1;          -- 回滚到保存点
COMMIT;                              -- 只保留第一条
```

## 行级锁

```sql
-- SELECT FOR UPDATE：悲观锁，锁定选中行
BEGIN;
SELECT * FROM accounts WHERE id = 1 FOR UPDATE;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
COMMIT;

-- SELECT FOR SHARE：共享锁，允许其他事务读但不允许写
SELECT * FROM accounts WHERE id = 1 FOR SHARE;

-- FOR NO KEY UPDATE：更轻量的写锁
-- FOR KEY SHARE：最轻量的锁
```

## 隔离级别

| 级别 | PostgreSQL 支持 | 说明 |
|------|----------------|------|
| `READ UNCOMMITTED` | 不支持（等同于 RC） | |
| `READ COMMITTED`（默认） | 支持 | 每条语句看到最新提交 |
| `REPEATABLE READ` | 支持 | 事务内一致读，检测写冲突 |
| `SERIALIZABLE` | 支持 | 最高级别，可串行化 |

```sql
-- 设置当前事务隔离级别
BEGIN TRANSACTION ISOLATION LEVEL REPEATABLE READ;
-- 或
SET TRANSACTION ISOLATION LEVEL SERIALIZABLE;
```
