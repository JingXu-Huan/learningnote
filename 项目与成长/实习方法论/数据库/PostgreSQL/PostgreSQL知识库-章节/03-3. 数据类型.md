# 3. 数据类型

## 数值类型

| 类型 | 说明 | 范围 |
|------|------|------|
| `SMALLINT` | 2 字节整数 | -32768 ~ 32767 |
| `INTEGER` | 4 字节整数 | -21亿 ~ 21亿 |
| `BIGINT` | 8 字节整数 | 很大 |
| `NUMERIC(p,s)` | 精确小数 | 任意精度 |
| `REAL` | 4 字节浮点 | 6 位小数精度 |
| `DOUBLE PRECISION` | 8 字节浮点 | 15 位小数精度 |
| `SERIAL` | 自增整数 | 等同 INTEGER + 序列 |
| `BIGSERIAL` | 自增大整数 | 等同 BIGINT + 序列 |

## 字符串类型

| 类型 | 说明 |
|------|------|
| `CHAR(n)` | 定长字符串，不足补空格 |
| `VARCHAR(n)` | 变长字符串，有长度限制 |
| `TEXT` | 变长字符串，无长度限制（推荐） |

> PostgreSQL 中 `TEXT` 和 `VARCHAR` 性能几乎无差别，推荐直接用 `TEXT`。

## 日期时间类型

| 类型 | 说明 | 精度 |
|------|------|------|
| `DATE` | 日期 | 年-月-日 |
| `TIME` | 时间 | 时:分:秒 |
| `TIMESTAMP` | 日期+时间（无时区） | 微秒 |
| `TIMESTAMPTZ` | 日期+时间（带时区） | 微秒 |
| `INTERVAL` | 时间间隔 | - |

## 特殊类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `BOOLEAN` | 布尔值 | `true` / `false` |
| `UUID` | 通用唯一标识符 | `'a0eebc99-...'` |
| `JSON` | JSON 文本存储 | `'{"name":"Tom"}'` |
| `JSONB` | JSON 二进制存储（可索引，推荐） | `'{"name":"Tom"}'` |
| `ARRAY` | 数组 | `integer[]`, `text[]` |
| `INET` | IP 地址 | `'192.168.1.1'` |
| `CIDR` | IP 网段 | `'192.168.1.0/24'` |
| `MACADDR` | MAC 地址 | `'08:00:2b:01:02:03'` |
| `BYTEA` | 二进制数据 | - |
| `ENUM` | 枚举类型 | 需先 `CREATE TYPE` |
