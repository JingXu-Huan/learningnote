# 4. 建表与约束

## 基本建表

```sql
CREATE TABLE users (
    id          BIGSERIAL PRIMARY KEY,
    username    VARCHAR(50) NOT NULL UNIQUE,
    email       TEXT NOT NULL,
    age         INTEGER CHECK (age >= 0 AND age <= 150),
    status      VARCHAR(20) DEFAULT 'active',
    tags        TEXT[],
    profile     JSONB,
    created_at  TIMESTAMPTZ DEFAULT NOW(),
    updated_at  TIMESTAMPTZ DEFAULT NOW()
);
```

## 约束类型

| 约束 | 说明 | 示例 |
|------|------|------|
| `PRIMARY KEY` | 主键（非空+唯一） | `id BIGSERIAL PRIMARY KEY` |
| `NOT NULL` | 非空 | `name TEXT NOT NULL` |
| `UNIQUE` | 唯一 | `email TEXT UNIQUE` |
| `CHECK` | 条件检查 | `CHECK (age > 0)` |
| `DEFAULT` | 默认值 | `DEFAULT NOW()` |
| `REFERENCES` | 外键 | `REFERENCES dept(id)` |

## 自增主键（推荐写法）

```sql
-- 方式一：SERIAL（旧写法，仍广泛使用）
CREATE TABLE t1 (
    id SERIAL PRIMARY KEY
);

-- 方式二：IDENTITY（SQL 标准，推荐 PostgreSQL 10+）
CREATE TABLE t2 (
    id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY
);

-- 方式三：IDENTITY 允许手动插入
CREATE TABLE t3 (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
);
```
