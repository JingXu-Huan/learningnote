# 1. Docker 一键启动（PowerShell）

## 快速启动

```powershell
docker run -d `
  --name postgres `
  -e POSTGRES_USER=jingxu `
  -e POSTGRES_PASSWORD=202430904Jx@ `
  -e POSTGRES_DB=testdb `
  -p 5432:5432 `
  -v pgdata:/var/lib/postgresql/data `
  postgres:16
```

## 参数说明

| 参数 | 说明 |
|------|------|
| `-d` | 后台运行 |
| `--name postgres` | 容器名称 |
| `-e POSTGRES_USER` | 超级用户名 |
| `-e POSTGRES_PASSWORD` | 用户密码 |
| `-e POSTGRES_DB` | 默认创建的数据库名 |
| `-p 5432:5432` | 端口映射（宿主机:容器） |
| `-v pgdata:/var/lib/postgresql/data` | 数据持久化（命名卷） |
| `postgres:16` | 镜像版本（可换 `15`、`14`、`latest`） |

## 常用运维命令

```powershell
# 进入 psql 交互终端
docker exec -it postgres psql -U postgres

# 查看容器日志
docker logs postgres

# 停止 / 启动 / 删除容器
docker stop postgres
docker start postgres
docker rm postgres

# 查看数据卷
docker volume inspect pgdata
```

## Docker Compose 版本（推荐项目使用）

```yaml
# docker-compose.yml
version: "3.8"
services:
  postgres:
    image: postgres:16
    container_name: postgres
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: 123456
      POSTGRES_DB: testdb
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
    restart: unless-stopped

volumes:
  pgdata:
```

```powershell
# 启动
docker compose up -d

# 停止
docker compose down

# 查看日志
docker compose logs -f postgres
```
