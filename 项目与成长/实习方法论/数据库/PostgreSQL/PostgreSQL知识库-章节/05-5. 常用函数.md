# 5. 常用函数

## 字符串函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `LENGTH(str)` | 字符长度 | `LENGTH('hello')` → 5 |
| `UPPER(str)` / `LOWER(str)` | 转大小写 | |
| `CONCAT(s1, s2, ...)` | 拼接字符串 | `CONCAT('a', 'b')` → ab |
| `SUBSTRING(str FROM pos FOR len)` | 截取（注意语法不同） | `SUBSTRING('hello' FROM 2 FOR 3)` → ell |
| `REPLACE(str, old, new)` | 替换 | |
| `TRIM(str)` | 去空格 | |
| `SPLIT_PART(str, delim, n)` | 按分隔符取第 n 段 | `SPLIT_PART('a-b-c', '-', 2)` → b |
| `STRING_AGG(expr, delim)` | 聚合拼接（等同 GROUP_CONCAT） | `STRING_AGG(name, ',')` |
| `POSITION(sub IN str)` | 子串位置（从 1 开始） | |
| `LEFT(str, n)` / `RIGHT(str, n)` | 取左/右 n 个字符 | |
| `LPAD(str, len, pad)` / `RPAD(...)` | 左/右填充 | |

## 日期时间函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `NOW()` / `CURRENT_TIMESTAMP` | 当前日期时间（带时区） | |
| `CURRENT_DATE` | 当前日期 | |
| `CURRENT_TIME` | 当前时间 | |
| `EXTRACT(field FROM ts)` | 提取年/月/日等 | `EXTRACT(YEAR FROM NOW())` |
| `DATE_TRUNC(field, ts)` | 截断到指定精度 | `DATE_TRUNC('month', NOW())` |
| `AGE(ts1, ts2)` | 两个时间差的年月日 | `AGE(NOW(), '2000-01-01')` |
| `TO_CHAR(ts, format)` | 格式化输出 | `TO_CHAR(NOW(), 'YYYY-MM-DD')` |
| `TO_TIMESTAMP(str, format)` | 字符串转时间戳 | `TO_TIMESTAMP('2024-01-01', 'YYYY-MM-DD')` |
| `INTERVAL` | 时间间隔运算 | `NOW() + INTERVAL '1 day'` |

> **与 MySQL 的区别**：PostgreSQL 没有 `DATE_FORMAT`，用 `TO_CHAR` 替代；日期运算用 `INTERVAL` 而非 `DATE_ADD`。

## 条件与类型转换

```sql
-- COALESCE：返回第一个非 NULL 值
SELECT COALESCE(nickname, username, '匿名用户') AS display_name FROM users;

-- NULLIF：相等返回 NULL
SELECT NULLIF(status, 'deleted') FROM users;

-- CASE WHEN THEN
SELECT
    CASE
        WHEN age < 18 THEN '未成年'
        WHEN age < 60 THEN '成年人'
        ELSE '老年人'
    END AS age_group
FROM users;

-- 类型转换（PostgreSQL 特有的 :: 语法）
SELECT '123'::INTEGER;          -- 字符串转整数
SELECT 123::TEXT;               -- 整数转字符串
SELECT '2024-01-01'::DATE;     -- 字符串转日期
SELECT price::NUMERIC(10, 2);  -- 精度转换

-- 也可以用标准的 CAST
SELECT CAST('123' AS INTEGER);
```
