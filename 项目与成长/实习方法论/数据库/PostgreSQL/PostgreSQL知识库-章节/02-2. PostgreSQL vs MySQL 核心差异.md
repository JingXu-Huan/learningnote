# 2. PostgreSQL vs MySQL 核心差异

| 维度 | PostgreSQL | MySQL |
|------|-----------|-------|
| 开源协议 | PostgreSQL License（类BSD） | GPL |
| SQL 标准兼容性 | 高度兼容 | 部分兼容 |
| JSON 支持 | `json` / `jsonb`（二进制，可索引） | `json`（文本，功能弱） |
| 数组类型 | 原生支持 `integer[]`、`text[]` 等 | 不支持 |
| 全文搜索 | 内置 `tsvector` / `tsquery` | 需外部方案（ES） |
| GIS 地理信息 | PostGIS 扩展（业界标准） | 基础支持 |
| 窗口函数 | 全版本支持 | 8.0+ |
| CTE 递归查询 | 支持 `WITH RECURSIVE` | 8.0+ |
| 自定义类型 | `CREATE TYPE` | 不支持 |
| 扩展机制 | `CREATE EXTENSION`（丰富生态） | 插件有限 |
| MVCC 实现 | 多版本共存（旧版本需 VACUUM 清理） | Undo Log |
| 默认隔离级别 | Read Committed | Repeatable Read |
| 大小写敏感 | 标识符小写折叠（双引号强制大小写） | 取决于操作系统 |
| 自增主键 | `SERIAL` / `GENERATED ALWAYS AS IDENTITY` | `AUTO_INCREMENT` |
