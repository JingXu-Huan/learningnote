# 不建议使用字段注入的原因

## 问题根源 ： Java 的 **字段初始化** 是在 **构造方法之前** 进行的！

```java
@Autowired
AliyunProperties aliyunProperties;
private final String endpoint = aliyunProperties.getEndpoint();
private final String bucketName = aliyunProperties.getBucketName();
private final String region = aliyunProperties.getRegion();
```

💥 **问题就出在这三行初始化语句上**。为什么？

------

### 🧠 Java 执行顺序（核心点）

> Java 的 **字段初始化** 是在 **构造方法之前** 进行的！

也就是说：当你写 `private final String endpoint = aliyunProperties.getEndpoint();` 时，`aliyunProperties` 还没有被 `@Autowired` 注入，它是 **null**！

于是你就会触发这句的经典报错：

```java
Caused by: java.lang.NullPointerException:
Cannot invoke "AliyunProperties.getEndpoint()" because "this.aliyunProperties" is null
```

------

## ✅ 正确的写法（两种）

### ✅【方式一：构造器注入，推荐】

```java
public class AliyunOSSOperator {

    private final String endpoint;
    private final String bucketName;
    private final String region;

    public AliyunOSSOperator(AliyunProperties aliyunProperties) {
        this.endpoint = aliyunProperties.getEndpoint();
        this.bucketName = aliyunProperties.getBucketName();
        this.region = aliyunProperties.getRegion();
    }

    // upload 方法略...
}
```

> ✅ 这是**最推荐**的方式，既不会空指针，也让你的类变得更干净利落！
