# 动态数据源使用教程
## 使用开源方案 dynamic-datasource-spring-boot-starter

> 它可以让你在运行时切换不同数据库，例如：主库（master）从库（slave）用户库（user）日志库（log）

## 使用步骤：

1. 引入依赖

SpringBoot2：

```xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>dynamic-datasource-spring-boot-starter</artifactId>
    <version>4.3.1</version>
</dependency>
```
SpringBoot3:
```xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>dynamic-datasource-spring-boot3-starter</artifactId>
    <version>4.3.1</version>
</dependency>
```

2. 在YAML中配置多个数据源：
```yaml
spring:
  datasource:
    dynamic:
      primary: master # 默认数据源
      strict: false

      datasource:
        master:
          url: jdbc:mysql://192.168.1.10:3306/master_db
          username: root
          password: 123456
          driver-class-name: com.mysql.cj.jdbc.Driver

        slave:
          url: jdbc:mysql://192.168.1.11:3306/slave_db
          username: root
          password: 123456
          driver-class-name: com.mysql.cj.jdbc.Driver
```
---
3. 使用
> 支持方法级，类级的数据源切换


* 方法级动态数据源 

```java
@Service
public class UserService {

    @DS("slave")
    public List<User> list() {
        return userMapper.selectList(null);
    }
}
```
执行时切换到slave库。
* 类级
```java
@Service
@DS("slave")
public class UserService {
}

```
整个类都走 slave。
